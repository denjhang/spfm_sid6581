# SID 6581 挂 SPFM：74LS374 + 74HCT02 + 74HCT32 + 74HC74 + 74HC164 接线表

> **本版取代 [接线表_374_02_123.md](接线表_374_02_123.md)（那颗 74HC123 不在库存里）。**
>
> 问题本身不变：SID 只在 **PHI2 上升沿** 且 `/CS`、`R/W` 同时为低时采样总线，
> 而 SPFM 的 `/WR` 只有数百纳秒，单次写入约有 80% 概率丢失且无任何反馈。
> 推导与实测见 [写入时序调试记录.md](写入时序调试记录.md) §3、§4。
>
> **本版的改动：用 PHI2 自己当节拍器，把写窗口拉成 N 个 PHI2 周期。**
> 不用 RC 单稳态——RC 的宽度随温度、器件、供电漂移，还得拿示波器标定；
> 而 PHI2 计数的窗口是「精确 N 个 1 µs」，晶振换成 0.985 MHz 也自动跟着变，不用重调。

## 1. 这个窗口要多长

先把三个硬约束写清楚，后面的取值都从这里来。

| 约束 | 数值 | 依据 |
|---|---|---|
| 下限 A：必须跨过至少一个 PHI2 上升沿 | ≥ 1 µs | 6581 datasheet：`TW` 从 φ2/CS/R-W 三者中最晚的那个算起，最小 350 ns |
| 下限 B：必须覆盖内部 18 周期轮转里可写的 6 个周期 | **≥ 12 µs** | 见本节末尾 |
| 上限：必须在下一条命令的地址相之前关断 | **< 20 µs** | 见 §1.2 |

### 1.1 为什么是 12 µs

reDIP-SID 的写条件（`gateware/sid_control.sv`）：

```systemverilog
w = ~bus_i.phi2 & ~bus_i.r_w_n && voice_cycle >= 1 && voice_cycle <= 6;
```

可写的相位是 18 周期轮转里的第 1–6 周期，**占 6 个 PHI2 周期，每 18 µs 出现一次**。

写窗口的长度为 `W`，起点相对 PHI2 是随机的。要保证「无论起点在哪都能撞进那 6 µs」，
需要

```
W + 6 ≥ 18   →   W ≥ 12 µs
```

即 **12 µs 是确定性下限**，不是建议值。窗口短于 12 µs 时命中是概率事件
（`W = 8 µs` 时约 75%，`W = 4 µs` 时约 53%）。

datasheet 只写了「φ2 上升沿 + /CS + R/W」三条电平条件，没有提 18 周期轮转。
按最严的模型（FPGA 软核）设计，两种情况下都能工作。

### 1.2 上限为什么是 20 µs

窗口开着的时候，SID 的 `/CS` 和 `R/W` 都是低，任何出现在 D 线上的字节都会被写进寄存器。
主机下一条命令的**地址字节**（内容 `addr & 0x1F`）必须落在窗口之外，否则会污染寄存器。

Path A 一条命令 4 字节 = 26.67 µs，两次命令的间隔就是 26.67 µs，
从本次数据相到位到下次地址相连 26 µs 左右。取 **20 µs** 作为设计上限，留余量。

### 1.3 取值

**目标窗口：13–14 µs（tap 取第 14 级）。** 同时满足 ≥12 和 <20，两侧余量都够。
按 §7 的接法仿真验证过：触发相位从 0 到 0.99 个周期变化时，实际窗口在
**13.0–14.0 µs** 之间，始终落在区间内。

U3 的两个触发器都要用，缺一个就不工作。

## 6. U4 = 74HCT32 引脚表（DIP-14，用 2 个门）

目标：`TRIG_n` **只在数据相写脉冲期间为低**：

```
TRIG_n = ¬(A0 ∧ ¬/WR ∧ ¬CSn) = ¬A0 ∨ /WR ∨ CSn
```

| 引脚 | 名称 | 接到 | 备注 |
|---|---|---|---|
| **1** | **1A** | **U2 pin4（nA0 = ¬A0）** | |
| **2** | **1B** | **SPFM /WR** | |
| **3** | **1Y** | **U4 pin4（2A）** | `t = OR(¬A0, /WR)` |
| **4** | **2A** | **U4 pin3（t）** | |
| **5** | **2B** | **SPFM CSn** | 低有效 |
| **6** | **2Y** | **U3 pin4（1/PRE）＋ U3 pin13（2/CLR）** | `TRIG_n`，一分为二，见 §7.1 |
| 7 | GND | GND | |
| 8, 9, 10 | 3A / 3B / 3Y | **3A、3B 接 GND** | 闲置门输入接地 |
| 11, 12, 13 | 4Y / 4A / 4B | **4A、4B 接 GND** | 闲置门输入接地 |
| 14 | VCC | **+5V**（旁挂 100nF） | |

### 6.1 真值表（本槽 CSn=0 时）

| A0 | /WR | LE | TRIG_n | 含义 |
|---|---|---|---|---|
| 0 | 1 | 0 | **1** | 空闲 |
| **0** | **0** | 1 | **1** | 地址相：**不触发** |
| **1** | **0** | 0 | **0 ↓** | **数据相：置位窗口锁存器** |
| 1 | 1 | 0 | **1** | 写脉冲结束，窗口靠计数自己关 |

本槽未选中（CSn=1）时 `TRIG_n` 恒为 1，任何相位都不触发。

> **设计要点**：不能用 `OR(LE, CSn)` 代替。`LE` 在空闲态也是 0（`NOR(0,1)=0`），
> 那样空闲期会误触发，在总线上产生虚假的 `/CS`+`R/W` 低脉冲。
> 必须用 `A0` 原信号判断数据相。

## 7. 核心：PHI2 计数的写窗口

### 7.1 结构

```
        TRIG_n ──┬─────────────→ U3A /PRE   （置位：开窗口）
                 └─────────────→ U3B /CLR   （清掉"数完了"标志）

 U3A 1Q ──┬──→ U5 A,B（移位串行输入）
          └──→ 窗口有效标志

 U3A 1/Q̄ ──→ Wn ──→ SID pin6 (/CS)
                  └→ SID pin7 (R/W)

 PHI2 ──────→ U5 CP, U6 CP   （同一个时钟）

 U6 QF (tap) ──→ U2 g3 反相 ──→ U3B /PRE   （置位"数完了"）

 U3B 2/Q̄ ──┬──→ U3A /CLR     （关窗口）
           └──→ U5 /MR, U6 /MR（顺手把链清空）

        ┌──── U3A (74HC74 第1个) ────┐   ┌──── U3B (74HC74 第2个) ────┐
TRIG_n→│/PRE                     Q →│   │/PRE ← U2 3Y (nTAP)        │
       │/CLR ← 2/Q̄               /Q →│──→│/CLR ← TRIG_n       2/Q →│─┬→ U3A /CLR
        └────────────────────────────┘   └───────────────────────────┘ └→ U5/U6 /MR
```

四句话：

1. **U3A 是窗口本身。** `TRIG_n` 拉低 → 异步置位 → `Q=1`、`/Q=0` → SID 的 `/CS` 和 `R/W` 同时为低。
2. **U5/U6 是计数器。** CP 接 PHI2，串行输入接 `U3A 1Q`。窗口一开，每个 PHI2 上升沿往链里推一个 1。
3. **数到第 N 格，U3B 记住"数完了"。** tap 变高 → 置位 U3B。它的 `2/Q̄` 同时做两件事：
   拉低 `U3A /CLR` 关掉窗口，拉低移位链的 `/MR` 把链清空。
4. **U3B 一直保持，直到下一次 `TRIG_n`。** 这样 tap 的上升沿只需要出现一瞬间；
   链被清空、tap 回落到 0 都不会让窗口重新打开。`TRIG_n` 到来时先清 U3B、再置 U3A，
   于是下一轮干净地重新开始。

**窗口长度 = 从触发到第 N 个 PHI2 上升沿，即 (N−1) … N 个 µs。** 不做 RC，不漂移。

第 2 个触发器不是可选的：如果只用 `¬tap` 直接清 U3A，链要花一个周期才把 tap 上的 1 移走，
那一个周期里窗口已经关了但 tap 还是 1，`/CLR` 仍被拉住，会出现时序依赖实现的毛刺。
用 U3B 当"完成锁存器"，逻辑与时序无关，更稳。

**`TRIG_n` 同时接 U3A `/PRE` 和 U3B `/CLR`，不会打架。** 这两个异步端短暂同时为低
（U3B 从清零到 `2/Q̄` 变高的约 15 ns 内），但 `TRIG_n` 的低电平持续数百纳秒，
`/CLR` 先释放、`/PRE` 后释放，74HC74 按"最后一个仍有效的异步端"决定输出，
所以 U3A 最终一定是 `Q=1`（窗口打开）。这是正确的期望状态。

顺带的好处：`2/Q̄` 同时清链，省掉了"靠移 0 自然冲掉"的 2–3 个周期不确定期，
每次写都从干净的全零链开始。上电时无论两半初值如何，第一次 `TRIG_n` 会同时清零，
所以也不需要额外的上电复位。

### 7.5 抽头选择表

`N` = 抽头的序号（= 窗口打开后第几个 PHI2 上升沿，该位变高）。

| 抽头 | N | 实际窗口 | 命中 18 周期轮转的概率 | 评价 |
|---|---|---|---|---|
| U5 QD | 4 | 3–4 µs | ≈53% | 太短，只能证明通路是通的 |
| U5 QF | 6 | 5–6 µs | ≈64% | |
| U5 QH | 8 | 7–8 µs | ≈75% | **只装 U5 时的最优点，配 `--repeat 2` 够用** |
| U6 QD | 12 | 11–12 µs | ≈97% | 临界 |
| **U6 QF** | **14** | **13–14 µs** | **100%** | **推荐值，确定性** |
| U6 QH | 16 | 15–16 µs | 100% | 仍在上限内，仿真最大 15.0 µs |

**默认接法：U6 pin11（QF，N=14）。** 只打算装一颗 HC164 时接 U5 pin13（QH，N=8）。

概率一列按 `(W+6)/18` 估算（`W` 取窗口最小值），仅为直观参考。
真实芯片若像 reDIP-SID 那样只看"PHI2 下降沿 + 电平"，那么任何 N≥1 都能写进去，
窗口只是给了更多余量。

## 8. 完整译码方程

```
LE      = NOR(A0, /WR)                      // U2 g1 → 374 CLK
nA0     = NOR(A0, A0) = ¬A0                 // U2 g2
t       = OR(nA0, /WR)                      // U4 g1
TRIG_n  = OR(t, CSn) = ¬A0 ∨ /WR ∨ CSn      // U4 g2
nTAP    = ¬TAP                              // U2 g3
Q1      = SR(置位=TRIG_n↓, 清零=¬Q2↓)        // U3A，窗口标志
Wn      = ¬Q1                               // U3A 1/Q̄ → SID /CS 与 R/W
链      = shift(Q1, CP=PHI2, 清=¬Q2低)       // U5 + U6，共 16 级
TAP     = 链的第 N 格                        // N=14（U6 QF）
Q2      = SR(置位=nTAP↓, 清零=TRIG_n↓)       // U3B，"数完了"锁存
```

| 信号 | [接线表_374_02.md](接线表_374_02.md) | 本方案 |
|---|---|---|
| `LE` | `NOR(A0, /WR)` | **不变** |
| `/CS_sid` | `OR(CSn, LE)` | **`Wn`** |
| `R/W` | **`/WR`（数百 ns）** | **`Wn`（≈14 µs）** |

`Wn` 只在 `A0=1 & CSn=0 & /WR↓` 时产生，地址相永远不会出现 `Wn`，
所以原来 `OR(CSn, LE)` 那套保护不再需要——保护条件已经内建在 `TRIG_n` 里。

### 8.1 时序波形

```
PHI2    ─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌──
         ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾

TRIG_n  ‾‾‾‾‾‾\_______________________/‾‾‾‾‾‾‾   （只有几百 ns）

Q1      ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\_______
                          ←── 14 个周期 ──→

Wn      ‾‾‾‾‾‾‾‾\__________________________/‾‾‾‾‾   （SID /CS + R/W）

链 Q1   ____/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\___________   第14格变高后立刻被 /MR 清零
TAP     ____________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\_________   只高一个沿的时间

Q2      ____________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾   保持到下一次 TRIG_n
```

窗口开着时 D 线上是稳定的数据字节，被反复采样 N 次写入同一个值——寄存器是纯锁存器，
重复写同一值无副作用。

### 8.2 链的清零由 U3B 直接做

数完之后 `U3B 2/Q̄` 拉低，同时接 `U5/U6 /MR` 和 `U3A /CLR`。所以链不是"慢慢移 0 冲掉"，
而是被硬清零，**每次写都从全 0 链开始**，第 N 格的位置每次都是同一个值。

这样 tap 的位置和写命令间隔无关，也可以用任意 N，包括 16（最后一级）——
不会出现"上一轮的 1 还没移出去就和新的一轮叠在一起"的情况。

### 8.3 上电初值

上电时 U3A/U3B/移位链的初值都是随机的，其中最坏的一种是：链里的 tap 位恰好是 1，
于是 `nTAP` 已经为低，与 `TRIG_n` 同时作用到 U3B 的 `/PRE` 和 `/CLR`。
74HC74 两端同时有效属于非法状态（两个输出都为高），这一次写只会得到很短的一个窗口。

**影响只有上电后的第一条写命令**，之后 U3B 被 `TRIG_n` 清掉、链被 `/MR` 清零，
就恢复正常。驱动 `sid_init()` 会连写 25 条寄存器清零，第一条丢掉不影响任何结果，
所以**不需要额外上电复位电路**。

如果希望第一条也稳定，上电后先单独发一次 `[slot,0x00,0x00,0x00]` 再开始正常初始化。

SPFM `IC` 只接 SID 的 `/RES`，不要接到 U3/U5/U6 的清零端——
`IC` 是脉宽不定的复位信号，接上去会在复位期间和 `TRIG_n` 打架。

## 10. 总线动作表

| A0 | /WR | CSn | LE | TRIG_n | Wn（Q̄） | 总线动作 | SID 侧 |
|---|---|---|---|---|---|---|---|
| 0 | 1 | x | 0 | 1 | 1 | 空闲 | 忽略 |
| **0** | **0**↓ | 0 | **↑ 1** | 1 | 1 | **地址相** | 忽略，374 抓住 `addr&0x1F` |
| 0 | ↑ | 0 | ↓ 0 | 1 | 1 | 地址相结束 | 374 保持地址 |
| **1** | **0**↓ | 0 | 0 | **0 ↓** | **0（≈14 µs）** | **数据相** | **窗口内必有一次锁存** |
| 1 | ↑ | 0 | 0 | 1 | 0（计数中） | 数据相结束 | 继续写同一值（无副作用） |
| x | x | x | x | 1 | 0（计数中） | 窗口计时 | 同上 |
| x | x | 1 | x | 1 | 1 | 本槽未选中 | 忽略 |

关键点：

1. **374 的 CLK 上升沿落在 `/WR` 下降的那一刻**（A0 已为 0、D 线上已是 `addr`），捕获地址安全。
2. **地址相 `LE=1` → `TRIG_n=1` → SID 被完全释放**，绝不会误写。
3. **数据相 `Wn` 低 ≈14 µs**，覆盖 1 个以上完整 18 周期轮转里的可写窗口，SID 必然锁存。
4. 同一个值被写多次没有副作用（SID 寄存器是纯锁存器）。

**不要照抄原 midi.c 用 374 的 Q7 驱动 R/W。** 那样写窗口会缩回 `/WR` 的宽度，
正好把 U3+U5/U6 的意义抹掉。Q7 空着。

## 11. 主机侧写入序列

SID 与 AY8910 在总线层同构，直接走固件**路径 A**（4 字节）：

```
[slot, 0x00, addr & 0x1F, data]
```

固件内部自动展开两次 BusWrite：

| 步骤 | 固件动作 | 总线上 | 结果 |
|---|---|---|---|
| 1 | A0=0，D=`addr&0x1F`，/WR 脉冲 | LE 上升沿 | 374 捕获 A0–A4 |
| 2 | A0=1，D=`data`，/WR 脉冲 | `TRIG_n` 下降沿 → `Wn` 拉低 ≈14 µs | SID 在窗口内锁存 |

**`0x1F` 掩码不能省。** 加上本接线后，`--repeat 1` 就应当稳定工作；
如果还需要 repeat 才有声音，说明窗口没生效，按 §14 的表查。

### 11.1 初始化

复位后 volume（0x18）= 0，**不写就没有声音**：

```
[slot, 0x00, 0x18, 0x0F]    // volume = 15
[slot, 0x00, 0x17, 0xF0]    // 谐振 + 滤波通道使能（按需）
[slot, 0x00, 0x16, CUTOFF]  // 截止频率（按需）
```

### 11.2 一个音符

```
[slot, 0x00, 0x00+7c, freq_lo]
[slot, 0x00, 0x01+7c, freq_hi]
[slot, 0x00, 0x05+7c, AD]
[slot, 0x00, 0x06+7c, SR]
[slot, 0x00, 0x04+7c, WAVE|1]    // 起音
```

## 12. 用库存里的其他片子替代 HC164

HC164 只是「PHI2 逐拍推 1 的移位链」。任何「共同时钟 + 串行/并行 D 触发器」都能替，
只要保证 **每个 PHI2 上升沿往前推一格**。tap 的序号就是级数。

| 型号 | 每片级数 | 接法差异 | 备注 |
|---|---|---|---|
| **74HC164** | 8 | 原生串行输入 A/B，`/MR` 接 **U3 pin8（2/Q̄）** | **首选，最省事** |
| **74HC595** | 8 | 串行输入 `DS`；`SHCP` 接 PHI2；`STCP` 也接 PHI2；`/OE` 接 GND；`/MR` 接 **U3 pin8** | `STCP` 不能悬空，否则输出永远是上电值。`STCP=SHCP` 会让 tap 比 HC164 晚半拍，等效级数 +1，选 tap 时按实测调一格 |
| **74174**（6 位 D-FF） | 6 | 每个 `D` 接前一级 `Q`，`CP` 全接 PHI2，`/CLR` 接 **U3 pin8** | 3 片 = 18 级，tap 取第 14 级。片间连线多，但逻辑最直白 |
| **74273**（8 位 D-FF） | 8 | 同上，`/MR` 接 **U3 pin8** | 2 片 = 16 级，比 2 片 HC164 多两级，tap 取第 14 级 |
| **74HC125** | — | 不是移位链 | 用作 `Wn` 的缓冲/扇出，见 §9 末尾 |

级联时注意：**所有片的 CP 必须是同一根 PHI2，且所有 `/CLR`、`/MR` 并在一起接
`U3 pin8`**。让它们同时清零，否则链里会出现两段 1，tap 提前变高、窗口缩短。

## 13. 374 与 573 的差异

| | 74LS374（本文） | 74HCT573 |
|---|---|---|
| 触发方式 | **上升沿** | 电平透明（LE 高穿透，低保持） |
| 捕获时刻 | `/WR` 下降沿 | 同左，但之后一直透明直到 LE 落 |
| 对「地址相期间 D 线变动」的容忍 | 更严格（只在边沿采样） | 更宽松（透明期间跟随） |
| 引脚排布 | 交错（Q0/D0/D1/Q1…） | 输入一排、输出一排 |
| 原始出处 | midi.c 原设计 | 通用替换 |

**两种都能跑**，因为每次 BusWrite 都有独立的 `/WR` 脉冲——`/WR` 在两个写之间一定回到高电平，
所以不存在「A0 在 /WR 低期间翻转」的情况。

**换成 373 / 574 对本项目毫无帮助。** 它们只影响地址锁存那一侧，
真正过短的是 `R/W` 的脉宽——那由 U3 + U5/U6 解决，与锁存器型号无关。

## 14. 上电与调试

按顺序量，前一项不对就别看后一项。

| 检查项 | 做法 |
|---|---|
| ① PHI2 | SID pin8 上应有干净 1 MHz（占空比接近 50%） |
| ② `LE` | U2 pin1：只在 A0=0 且 /WR=0 时为高 |
| ③ `TRIG_n` | U4 pin6：空闲恒高，写数据相时出现一个低脉冲。若空闲也低 → 检查 U2 pin4 是否为 `¬A0`，**不要用 `OR(LE, CSn)`** |
| ④ 窗口 | U3 pin6（`Wn`）：每次写数据相后拉低 **≈14 µs**，宽度随触发相位在 13–14 µs 之间变化（正常）。量不到 → U3 pin4 是否接 U4 pin6、U3 pin1 是否被 U3 pin8 拉住 |
| ⑤ 抽头 | 探 U6 pin11（tap）：每个 PHI2 沿往后推一格，第 14 个沿变高，随即因为 `/MR` 被清掉而回落 |
| ⑥ 窗口太短/太长 | 换 tap：`Wn` 宽度 ≈ tap 序号 µs。想 8 µs 就把 tap 移到 U5 pin13（同时 U3 pin10 也改接到那里） |
| ⑦ 连写时窗口越来越长、或第二次不响应 | 「数完了」标志没被清。U3 pin8 的常态：数完后为低，下一次 `TRIG_n` 到来时变高、再数完又回低。若一直保持低 → U3 pin13 是否接 U4 pin6 |
| ⑧ 完全没声音、`Wn` 恒低 | U3 pin1 一直被拉低。量 U3 pin8 是否恒高（说明"数完了"从没置位，tap 没到）或恒低（说明从没被清） |
| ⑨ 空闲时也有输出 | `TRIG_n` 接错，见 ③ |
| ⑩ 只有部分寄存器能写 | 量 U1 pin12（Q4）到 SID pin13 的通断——A4 断了就只有 0x00–0x0F 能用 |
| ⑪ 音量写了没反应 | 检查 12 V（pin28）与 5 V（pin25）是否都在；6581 缺 12 V 完全无声 |
| ⑫ 上电初态 | 374 的 Q 上电后是不定态。先写一次 `[slot,0x00,0x00,0x00]` 让它归零 |

**验收标准**：`--write-mode two-phase --repeat 1 --delay 0` 单次写入就能稳定出声，
且 `scale` 每个音高都正确。做到这两条，`--repeat` 就可以彻底撤掉了。

## 15. 一句话总结

D0–D7 共享；A0 当相位；`LE = NOR(A0, /WR)` 敲 374 的上升沿；`TRIG_n = ¬A0 ∨ /WR ∨ CSn`
只在数据相写脉冲期间拉低；**74HC74 上半锁出 `Wn`（驱动 `/CS` + `R/W`），
74HC164 两级链数 14 个 PHI2 周期，第 14 格经下半锁存成"数完了"再关掉窗口**；
1 MHz 晶振既喂 PHI2 又当窗口节拍；主机一条 `[slot, 0x00, addr&0x1F, data]` 完成一次寄存器写。

**这一版的本质：把「写窗口能否撞上 PHI2 采样点」从依赖 RC 精度的模拟问题，
变成数时钟周期就能保证的确定性问题。**
