# SID 6581 挂 SPFM：74LS374 + 74HCT02 + 74HC123 接线表（已废弃）

> **⚠ 本文已废弃。现行方案：[接线表_374_02_min.md](接线表_374_02_min.md)（三颗 IC）。**
>
> 废弃原因：手上没有 74HC123；而且 RC 单稳态的宽度随温度、器件、供电漂移，
> 必须逐块用示波器标定。后来改用 PHI2 计数（74HC74 + 74HC164），
> 窗口精确等于 N 个 PHI2 周期，不用标定、自动跟随晶振频率。
> 本文保留作为设计推演记录。

> **本版相对 [接线表_374_02.md](接线表_374_02.md) 的唯一改动：把写窗口拉宽。**
>
> 原方案里 SID 的 `R/W` 直接接 SPFM `/WR`，脉宽只有数百纳秒；而 SID 只在 **PHI2 上升沿**
> 且 `/CS`、`R/W` 同时为低时才锁存数据，并且还要落在内部 18 周期轮转的第 1–6 周期，
> 所以单次写入约有 80% 概率丢失且无任何反馈。实测与推导见
> [写入时序调试记录.md](写入时序调试记录.md) §4。
>
> 本版加一颗 **74HC123 可重触发单稳态**，把数据相的 `/CS` 与 `R/W` 同时拉低到
> **≈5.6 µs**，覆盖 5 个完整 PHI2 周期，命中窗口从概率事件变成确定性事件。
> 地址锁存与"地址相不误写"的保护逻辑完全保留。

## 5. U4 = 74HCT32 引脚表（DIP-14，用 2 个门）

目标：`TRIG_n` **只在数据相写脉冲期间为低**，即

```
TRIG_n = ¬(A0 ∧ ¬/WR ∧ ¬CSn) = ¬A0 ∨ /WR ∨ CSn
```

用两次 OR 实现（第一个 OR 吃掉 `¬A0` 和 `/WR`，第二个吃掉 `CSn`）：

| 引脚 | 名称 | 接到 | 备注 |
|---|---|---|---|
| **1** | **1A** | **U2 pin4（nA0 = ¬A0）** | |
| **2** | **1B** | **SPFM /WR** | |
| **3** | **1Y** | **U4 pin4（2A）** | `t = OR(¬A0, /WR)` |
| **4** | **2A** | **U4 pin3（t）** | |
| **5** | **2B** | **SPFM CSn** | 低有效 |
| **6** | **2Y** | **U3 pin2（1/A）** | `TRIG_n = OR(t, CSn)` |
| 7 | GND | GND | |
| 8, 9, 10 | 3A / 3B / 3Y | **3A、3B 接 GND** | 闲置门输入接地 |
| 11, 12, 13 | 4Y / 4A / 4B | **4A、4B 接 GND** | 闲置门输入接地 |
| 14 | VCC | **+5V**（旁挂 100nF） | |

```
g1:  t      = OR(¬A0, /WR)
g2:  TRIG_n = OR(t, CSn)  = ¬A0 ∨ /WR ∨ CSn
```

### 5.1 真值表（本槽 CSn=0 时）

| A0 | /WR | LE | TRIG_n | 含义 |
|---|---|---|---|---|
| 0 | 1 | 0 | **1** | 空闲 |
| **0** | **0** | **1** | **1** | 地址相：**不触发** |
| **1** | **0** | 0 | **0 ↓** | **数据相：下降沿触发单稳态** |
| 1 | 1 | 0 | **1** | 写脉冲结束，回空闲 |

本槽未选中（CSn=1）时 `TRIG_n` 恒为 1，任何相位都不触发。

> **设计要点**：不能用 `OR(LE, CSn)` 代替。`LE` 在空闲态也是 0（`NOR(0,1)=0`），
> 那样空闲期会误触发单稳态，在总线上产生虚假的 `/CS`+`R/W` 低脉冲。
> 必须用 `A0` 原信号判断数据相。

### 5.2 若手上只有 74HCT00（NAND）

```
nA0    = NAND(A0, A0)              // g1 反相 → ¬A0
TRIG_n = NAND(nA0, /WR)            // g2: ¬(¬A0 ∧ /WR)
```
这只是 `¬(¬A0 ∧ /WR) = A0 ∨ ¬/WR`，还缺 CSn 项。需再接：
```
t      = NAND(nA0, /WR)            // = A0 ∨ ¬/WR
TRIG_n = NAND( NAND(t, CSn), NAND(t, CSn) )   // 三级，需 4 个门
```
**建议直接用 74HCT32**，两级搞定。若只有 00，也能用 4 个门全部用满实现。

## 6. U3 = 74HC123 引脚表（DIP-16，用第 1 个单稳态）

| 引脚 | 名称 | 接到 | 备注 |
|---|---|---|---|
| **2** | **1/A（触发，下降沿有效）** | **U4 pin6（TRIG_n）** | |
| 1 | 1/CLR（复位，低有效） | **+5V** | 不用复位功能，必须接高 |
| **3** | **1B（触发，上升沿有效）** | **GND** | 只用下降沿触发 |
| 15 | 1/REXT | **R = 20kΩ → +5V** | |
| 14 | 1/CEXT | **C = 1nF → GND** | |
| 13 | 1/Q（正相输出） | **悬空** | 不用 |
| **4** | **1/Q̄（反相输出）** | **SID pin6（/CS）＋ SID pin7（R/W）** | **`Wn`，低有效 ≈5.6 µs** |
| 16 | VCC | **+5V**（旁挂 100nF） | |
| 8 | GND | GND | |
| 5 | 2/A | GND | 第 2 个单稳态闲置 |
| 6 | 2/CLR | GND | 闲置时 CLR 接 GND 保持复位 |
| 7 | 2B | GND | |
| 9, 10 | 2/REXT, 2/CEXT | 悬空 | |
| 11, 12 | 2/Q, 2/Q̄ | 悬空 | |

**必须用可重触发接法**：`/A` 触发、`B` 接 GND、`CLR` 接高。每次 `TRIG_n` 的下降沿都会
**重新开始**计时，连续写不会累积成超长脉冲。

`tw` 需示波器实测标定一次。目标 **≥3 µs**（覆盖 3 个 PHI2 周期和 1 个完整 18 周期轮转），
**必须 < 20 µs**（固件两条 BusWrite 之间的间隔），否则会跨到下一个字节。
`R = 20 kΩ + C = 1 nF` 给 ≈5.6 µs，两侧各留约 2 倍余量。

> `tw ≈ 0.28 × R × C × (1 + 1/Vcc)`（Vcc 单位 V），5 V 下 `0.28 × 20e3 × 1e-9 = 5.6 µs`。

## 7. 完整译码方程

```
LE      = NOR(A0, /WR)                  // U2 g1 → 374 的 CLK
nA0     = NOR(A0, A0) = ¬A0             // U2 g2，反相器
t       = OR(nA0, /WR)                  // U4 g1
TRIG_n  = OR(t, CSn) = ¬A0 ∨ /WR ∨ CSn  // U4 g2
Wn      = 单稳态(Q̄, tw ≈ 5.6 µs)        // U3，TRIG_n 下降沿触发
/CS_sid = Wn                            // → SID pin6
R/W     = Wn                            // → SID pin7
```

与原方案对比：

| 信号 | 原方案 | 本方案 |
|---|---|---|
| `LE` | `NOR(A0, /WR)` | **不变** |
| `/CS_sid` | `OR(CSn, LE)` | **`Wn`** |
| `R/W` | **`/WR`（数百 ns）** | **`Wn`（≈5.6 µs）** |

`Wn` 只在 `A0=1 & CSn=0 & /WR↓` 时产生，地址相永远不会出现 `Wn`，
所以原来 `OR(CSn, LE)` 那套保护不再需要——保护条件已经内建在 `TRIG_n` 里。

## 9. 总线动作表

| A0 | /WR | CSn | LE | TRIG_n | Wn | 总线动作 | SID 侧 |
|---|---|---|---|---|---|---|---|
| 0 | 1 | x | 0 | 1 | 1 | 空闲 | 忽略 |
| **0** | **0**↓ | 0 | **↑ 1** | 1 | 1 | **地址相** | 忽略，374 抓住 `addr&0x1F` |
| 0 | 0 | 0 | 1 | 1 | 1 | 地址相持续 | 忽略 |
| 0 | ↑ | 0 | ↓ 0 | 1 | 1 | 地址相结束 | 374 保持地址 |
| **1** | **0**↓ | 0 | 0 | **0 ↓** | **0（≈5.6 µs）** | **数据相** | **采到 PHI2 沿即锁存** |
| 1 | ↑ | 0 | 0 | 1 | 0（计完） | 数据相结束 | 继续写同一值（无副作用） |
| x | x | 1 | x | 1 | 1 | 本槽未选中 | 忽略 |

关键点：

1. **374 的 CLK 上升沿落在 `/WR` 下降的那一刻**（A0 已为 0、D 线上已是 `addr`），捕获地址安全。
2. **地址相 `LE=1` → SID 被完全释放**，绝不会误写。
3. **数据相 `Wn` 低 5.6 µs**，覆盖 5 个 PHI2 上升沿和 5 个完整 18 周期轮转，
   SID 一定能在某个"轮转第 1–6 周期"的窗口内锁存。
4. 同一个值被写多次没有副作用（SID 寄存器是纯锁存器）。

### 9.1 为什么 5.6 µs 是安全区间

| 约束 | 数值 | 说明 |
|---|---|---|
| 下限 | **≥3 µs** | 必须覆盖 ≥3 个 PHI2 上升沿，且 ≥1 个完整 18 周期轮转中的第 1–6 周期 |
| 上限 | **<20 µs** | 固件两条 BusWrite 之间间隔（Path B 3 字节 = 20 µs）；超过会跨到下一字节 |
| 推荐 | **5.6 µs** | `R=20kΩ, C=1nF`，上下各留约 2 倍余量 |

## 10. 主机侧写入序列

SID 与 AY8910 在总线层同构，直接走固件**路径 A**（4 字节）：

```
[slot, 0x00, addr & 0x1F, data]
```

固件内部自动展开两次 BusWrite：

| 步骤 | 固件动作 | 总线上 | 结果 |
|---|---|---|---|
| 1 | A0=0，D=`addr&0x1F`，/WR 脉冲 | LE 上升沿 | 374 捕获 A0–A4 |
| 2 | A0=1，D=`data`，/WR 脉冲 | `TRIG_n` 下降沿 → `Wn` 拉低 5.6 µs | SID 写入已锁地址 |

**`0x1F` 掩码不能省**。

### 10.1 初始化

复位后 volume（0x18）= 0，**不写就没有声音**：

```
[slot, 0x00, 0x18, 0x0F]    // volume = 15
[slot, 0x00, 0x17, 0xF0]    // 谐振 + 滤波通道使能（按需）
[slot, 0x00, 0x16, CUTOFF]  // 截止频率（按需）
```

### 10.2 一个音符

```
[slot, 0x00, 0x00+7c, freq_lo]
[slot, 0x00, 0x01+7c, freq_hi]
[slot, 0x00, 0x05+7c, AD]
[slot, 0x00, 0x06+7c, SR]
[slot, 0x00, 0x04+7c, WAVE|1]    // 起音
```

## 11. 可选改动

### 11.1 Q7 锁 R/W（照抄原 midi.c）— 本版**不要**这么做

原 midi.c 让 374 的 Q7 驱动 SID 的 R/W，靠"地址 ≤0x18 时 bit7 恒 0"锁成写。
本方案里 `R/W` 已由 `Wn` 驱动，改成 Q7 会让写窗口又缩回 `/WR` 的宽度，
**正好把这个改造的意义抹掉**。保留 Q7 空着。

### 11.2 多颗 SID 模块

- 两颗 SID 共用 U1（地址总线相同）、U2 的 `LE`；
- **74HC123 是双单稳态，一颗 U3 正好带两颗 SID**，不需要第二颗；
- 每颗各需一套 U4 门（`TRIG_n_x = ¬A0 ∨ /WR ∨ CSn_x`），
  一颗 74HCT32 的 4 个门可以带 2 颗（每颗 2 门）。

## 12. 374 与 573 的差异

| | 74LS374（本文） | 74HCT573 |
|---|---|---|
| 触发方式 | **上升沿** | 电平透明（LE 高穿透，低保持） |
| CLK/LE 上升沿时刻 | `/WR` 下降沿 | 同左，但之后一直透明直到 LE 落 |
| 对"地址相期间 D 线变动"的容忍 | **更严格**（只在边沿采样） | 更宽松（透明期间跟随） |
| 引脚排布 | 交错（Q0/D0/D1/Q1…） | 输入一排、输出一排 |
| 原始出处 | midi.c 原设计 | 通用替换 |

**两种都能跑**，因为每次 BusWrite 都有独立的 `/WR` 脉冲——`/WR` 在两个写之间一定回到高电平，
所以不存在"A0 在 /WR 低期间翻转"的情况。

> **换成 373 / 574 对本项目毫无帮助。** 它们只影响地址锁存那一侧，
> 而真正过短的是 `R/W` 的脉宽。574 也只是换了个锁存器型号，与本问题无关。

## 13. 上电与调试

| 检查项 | 做法 |
|---|---|
| 上电初始态 | 374 的 Q 在上电后是不定态。写一次 `[slot,0x00,0x00,0x00]` 让它先归零 |
| 无声 | 先确认写过 `0x18 = 0x0F`（音量）；再确认 PHI2 有 1MHz |
| 只有部分寄存器能写 | 量 U1 pin12（Q4）到 SID pin13 的通断——A4 断了就只有 0x00–0x0F 能用 |
| **写入丢一半（本版要解决的）** | **量 U3 pin4 的低电平宽度，必须 ≥3 µs 且 <20 µs** |
| **连写时脉冲越来越长** | 单稳态没接成可重触发。检查 U3 pin1（CLR）是否为高、pin3（B）是否接 GND |
| **完全没声音、U3 pin4 恒高** | 量 U4 pin6：正常应在写数据相时出现低脉冲。若恒高，查 U2 pin4 是否为 `¬A0` |
| **空闲时也有输出** | `TRIG_n` 接错。必须是 `¬A0 ∨ /WR ∨ CSn`，不能用 `OR(LE, CSn)` |
| 写入地址错位 | 量 U2 pin1 是否只在 A0=0 且 /WR=0 时为高 |
| 音量写了没反应 | 检查 12V（pin28）与 5V（pin25）是否都在；6581 缺 12V 完全无声 |

---

## 14. 一句话总结

D0–D7 共享；A0 当相位；`LE = NOR(A0, /WR)` 敲 374 的上升沿；
`TRIG_n = ¬A0 ∨ /WR ∨ CSn` 只在数据相写脉冲期间拉低；
**74HC123 把它展成 ≈5.6 µs 低脉冲 `Wn`，同时驱动 `/CS` 和 `R/W`**，
覆盖 5 个 PHI2 上升沿和 5 个完整 18 周期轮转，SID 必然锁存；
1MHz 晶振喂 PHI2；主机一条 `[slot, 0x00, addr&0x1F, data]` 完成一次寄存器写。

**加这一颗 123 的意义：把"写入是否命中 PHI2 采样窗口"从 ~20% 的概率事件变成确定性事件，
从而不再需要靠 repeat 掩盖丢写，音高也就能正确跟随指令。**
