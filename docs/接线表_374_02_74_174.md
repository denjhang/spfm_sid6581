# 方案 C：74174 ×3（6 位并行 D 触发器）

> 共用部分（U1 74LS374、U2 74HCT02、U3 74HC74、U4 74HCT32、译码方程、
> 主机侧写入序列、调试）见 [接线表_374_02_74.md](接线表_374_02_74.md)。
> **本文只写移位链这一段。**

## 1. 追加器件

| 位号 | 型号 | 作用 |
|---|---|---|
| U5 | 74174 / 74HC174（6 位 D-FF，带 /CLR） | 计数链第 1–6 级 |
| U6 | 74174 / 74HC174 | 计数链第 7–12 级 |
| U7 | 74174 / 74HC174 | 计数链第 13–18 级 |
| — | 100nF ×3 | 每片一颗去耦 |

**为什么要三片**：74174 每片只有 6 级，要凑到 14 级必须三片（6+6+6=18）。
比 HC164 方案多一片、片间连线也多，好处是逻辑最直白——没有"串行/锁存"这种内部结构，
每个触发器就是一个 D-FF，`Q` 直接当下一级 `D`。

## 2. 用 D-FF 搭移位链的原理

74174 是**并行** D 触发器：6 个触发器共用一个时钟，各自的 D 独立。
把它接成移位链只需要把每级的输入接到前一级的输出：

```
U5:  D1 ← U3.Q            U6:  D1 ← U5.Q6          U7:  D1 ← U6.Q6
     D2 ← U5.Q1               D2 ← U6.Q1               D2 ← U7.Q1
     D3 ← U5.Q2               D3 ← U6.Q2               D3 ← U7.Q2
     D4 ← U5.Q3               D4 ← U6.Q3               D4 ← U7.Q3
     D5 ← U5.Q4               D5 ← U6.Q4               D5 ← U7.Q4
     D6 ← U5.Q5               D6 ← U6.Q5               D6 ← U7.Q5
```

所有片的 `CP` 接同一根 PHI2。因为芯片内部 `Q→D` 的连线是**片内**的，
同一时钟沿上每级拿到的是**上一拍**的前级值，所以这就是标准移位链，不是锁存穿透。

**片间连一根线**：U6 的 D1 接 U5 的 Q6，U7 的 D1 接 U6 的 Q6。

## 4. 抽头

14 级 = U5 的 6 级 + U6 的 6 级 + U7 的 2 级，所以 **tap = U7 pin5（Q2）**。
接 U2 的 3A（pin8）和 3B（pin9）并联，U2 的 3Y（pin10）输出 `nTAP` 接 U3 pin10（2/PRE）。

| 抽头 | 级数 | 窗口 | 用途 |
|---|---|---|---|
| U5 pin14（Q6） | 6 | 5–6 µs | 只装一片时用 |
| U6 pin14（Q6） | 12 | 11–12 µs | 只装两片时用（临界） |
| **U7 pin5（Q2）** | **14** | **13–14 µs** | **默认，确定性** |
| U7 pin7（Q3） | 15 | 14–15 µs | |

## 5. 接线注意事项

1. **三片的 `CP` 必须是同一根 PHI2**，从 Y1 输出各自引线，不要串接。
2. **三片的 `/CLR` 必须并在一起接 U3 pin8**。74174 的 /CLR 每片只驱动 6 级，
   但必须同时动作——只清一片会让那一级的 1 提前消失，tap 位置漂移。
3. **74174 没有 Q̄ 输出**，所以只能取 Q。本设计本来也只用 Q。
4. **不要用 74LS174 驱动 CMOS 输入**（SID 的 /CS、R/W）——本设计里 174 只驱动 U2 的
   NOR 输入和下一级 D，逻辑门是 5 V 的，LS 完全够用。如果你手上只有 LS174，也可以用。
5. **上电时 /CLR 要能拉高**。若 U3 上电为不定态导致 `/CLR` 持续为低，链不工作——
   写一次任何寄存器即恢复正常（`TRIG_n` 会清 U3B）。

6. **为什么分立 D-FF 串链不会"追尾"**：每级 `D` 来自前一级 `Q`，两者同一个时钟沿动作。
   这要求前级 `Q` 的传播延迟（`tpd`，74HC 在 5 V 下约 13–25 ns）大于后级 `D` 的保持时间
   （约 5 ns），否则新值会在旧值被采到之前就冲掉。74174 / 74HC174 都满足，
   1 MHz 下余量 100 倍。同型号整批用最省心。

## 6. 调试

| 现象 | 检查 |
|---|---|
| 链完全不动 | 某片 `CP`（pin15）没接到 PHI2 |
| 只有 U5 会动 | 级联断了：量 U5 pin14 → U6 pin3、U6 pin14 → U7 pin3 |
| tap 在第 6 级就变高 | U6 的 D1 接错了（接到了 U5 的 Q5 而不是 Q6） |
| 窗口约 11–12 µs | tap 取到了 U6 pin14，改到 U7 pin5 |
| 某一片的输出全为 0 | 该片 `/CLR`（pin1）被拉低，或 VCC/GND 没接 |
| 每级都晚一格 | 正常。D-FF 链每级延迟恰好一个 PHI2 周期 |
