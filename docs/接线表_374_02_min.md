## 0. 网络标签总表

| 标签 | 由谁产生 | 接到谁 | 含义 |
|---|---|---|---|
| `D0`–`D7` | SPFM D0–D7 | U1 的 D0–D7 ＋ SID 的 D0–D7（同一组网） | 分时复用：地址相放 `addr&0x1F`，数据相放 data |
| `A0` | SPFM A0 | U2 pin2（1A）＋ U2 pin5（2A） | 相位位：0 = 地址相，1 = 数据相 |

| `/RD` | SPFM /RD | **不接** | 总线读选通，用途固定，不可挪用 |
| `IC` | SPFM IC | SID pin5（/RES） | 低有效复位 |
| `PHI2` | Y1 晶振输出 | SID pin8 | 1 MHz（8580 用 0.985 MHz） |
| `LE` | U2 pin1（1Y） | U1 pin11（CLK） | 地址锁存时钟，`LE = NOR(A0, /WR)` |
| `nA0` | U2 pin4（2Y） | U3 pin1（1A） | `nA0 = ¬A0` |
| **`TRIG_n`** | **U3 pin6（2Y）** | **SID pin6（/CS）** | **写选通，数据相 + 本槽 + /WR 低时为低** |
| `SID_A0`–`SID_A4` | U1 Q0–Q4 | SID pin9–pin13 | 锁存后的寄存器地址 |

只有 10 个标签。旧版里那些 `nTRIG`、`Wn`、`QW`、`DONE_n` 全部不存在了。

## 1. 电路的全部内容

```
LE      = NOR(A0, /WR)                  // U2 g1 → 374 的 CLK
nA0     = NOR(A0, A0) = ¬A0             // U2 g2 → 反相器
TRIG_n  = OR(nA0, /WR, CSn)             // U3 g1 + g2
        = ¬A0 ∨ /WR ∨ CSn
```

就三条。`TRIG_n` 直接送 SID 的 `/CS`，SPFM 的 `/WR` 直接送 SID 的 `R/W`：

| `A0` | `/WR` | `CSn` | `LE` | **`TRIG_n`** | **`/WR`→R/W** | SID 侧 |
|---|---|---|---|---|---|---|
| x | 1 | x | 0 | **1** | **1** | 释放 |
| 0 | 0 | 0 | **1** | **1** | **0** | 374 抓地址；`/CS` 仍高，**SID 不响应** |
| **1** | **0** | **0** | 0 | **0** | **0** | **`/CS` 与 `R/W` 同时低 → 写入** |
| x | x | 1 | x | **1** | x | 本槽未选中，忽略 |

**唯一必须保住的性质**：地址相期间 `/CS` 必须是高。`TRIG_n` 里有 `¬A0` 这一项，
所以地址相（`A0=0`）时它恒为高，SID 完全不看总线。这一点丢了就会在地址相误写，
表现为"每次改频率都重启包络"的咔哒声。

## 2. 器件清单

| 位号 | 型号 | 作用 | 封装 |
|---|---|---|---|
| U1 | **74LS374**（或 374 / 573 任何后缀） | 8 位 D 触发器，锁 A0–A4 | DIP-20 |
| U2 | **74HCT02**（4 NOR，用 2 个） | `LE`、反相 `A0` | DIP-14 |
| U3 | **74HCT32**（4 OR，用 2 个） | 生成 `TRIG_n` | DIP-14 |
| Y1 | 1 MHz 有源晶振（6581）；8580 用 0.985 MHz | `PHI2` | — |
| — | 100nF ×3 | U1–U3 各一颗去耦 | — |
| — | 2n2 ×2 | SID 滤波电容 | — |
| — | 10µF | 音频耦合 | — |

**三颗 IC。** 全部由 5 V 驱动，LS / HC / HCT 后缀可以随便混用。

74HCT02 的两个闲置门、74HCT32 的两个闲置门，**输入必须接 GND**，不能悬空。
悬空的 CMOS 输入电平不确定，会在相邻门之间串进噪声。

## 5. 为什么三颗就够了

### 5.1 曾经的错误结论

2026-11-19 那轮调试得出的结论是"74HC74 不可省，跳过它单次写入会明显失真"。
**这个结论是错的**，错在当时的实验条件：

旧实验里 `TRIG_n` **同时驱动 `/CS` 和 `R/W` 两个脚**。拆掉 74HC74 时，
`TRIG_n` 一个 74HCT32 输出要同时带两个 SID CMOS 输入外加走线电容，
边沿被拖慢，而 SID 那一刻要同时采两根线——于是"单次写入失真"。

现在的接法是 `TRIG_n` 只带 `/CS` 一个负载，`R/W` 由 SPFM 的 `/WR` 直接驱动。
两条负载各自独立，`/WR` 那一路几乎无负载，问题消失。

**教训：当时把"一个门带两个负载"的驱动问题，误判成了"必须整形"。**

### 5.2 那么 SID 到底是不是同步总线

早期依据 reDIP-SID 的 RTL 推断：

```systemverilog
w = ~bus_i.phi2 & ~bus_i.r_w_n && voice_cycle >= 1 && voice_cycle <= 6;
```

据此认为写入必须落在 PHI2 的特定相位，甚至设计了用 PHI2 计数把窗口拉到 13–14 µs 的电路。
**实测否定了这个推断**：`/WR` 的低电平窗口只占 1 MHz PHI2 周期的约 20%，
如果真要求跨过上升沿，应该有 80% 丢写，而现在是稳定写入。

结论：**6581 在这里表现为异步写器件**——`/CS` 与 `R/W` 同时为低就锁存，
和 YM2163 / YM7129 那些芯片没有本质区别。datasheet 里 `TW` 的措辞
（"从 φ2、CS、R/W 三者中最晚发生的那一个开始算"）是针对标准 C64 读写时序的保守描述，
不构成"必须等 PHI2"的约束。

那 18 周期轮转是 reDIP-SID 这颗 FPGA 软核**内部**的写调度，不是总线侧要求。

### 5.3 什么地方仍然必须小心

| 事项 | 原因 |
|---|---|
| 地址相 `/CS` 必须为高 | `TRIG_n` 里的 `¬A0` 就是干这个的。丢了会在地址相误写，听起来是每次改频率都咔哒 |
| `IC` 只接 SID 的 `/RES` | 它是全局复位，接到别处会打断播放 |
| `/RD` 不要挪用 | 总线协议固定 |
| 闲置门输入接 GND | 悬空 CMOS 输入电平不确定 |
| 374 的 Q7 空着 | 用它驱动 R/W 会把窗口缩回 `/WR` 宽度，且与 `/CS` 不同源 |

## 7. 主机侧写入序列

走固件**路径 A**（4 字节）：

```
[slot, 0x00, addr & 0x1F, data]
```

| 步骤 | 固件动作 | 总线上 | 结果 |
|---|---|---|---|
| 1 | A0=0，D=`addr&0x1F`，/WR 脉冲 | `LE` 上升沿，`TRIG_n`=1 | 374 捕获 A0–A4；SID 的 `/CS` 为高，不响应 |
| 2 | A0=1，D=`data`，/WR 脉冲 | `TRIG_n` 拉低，`/WR` 拉低 | `/CS` 与 `R/W` 同时为低，写入 |

**`0x1F` 掩码不能省**（保证地址字节 bit7=0）。

**不要照抄原 midi.c 用 374 的 Q7 驱动 R/W。** 那样 R/W 的窗口缩回 `/WR` 宽度，
而且和 `/CS` 又变成不同源、有偏斜。Q7 空着。

### 7.1 初始化

复位后 volume（0x18）= 0，**不写就没有声音**：

```
[slot, 0x00, 0x18, 0x0F]    // volume = 15
[slot, 0x00, 0x17, 0xF0]    // 谐振 + 滤波通道使能（按需）
[slot, 0x00, 0x16, CUTOFF]  // 截止频率（按需）
```

### 7.2 一个音符

```
[slot, 0x00, 0x00+7c, freq_lo]
[slot, 0x00, 0x01+7c, freq_hi]
[slot, 0x00, 0x05+7c, AD]
[slot, 0x00, 0x06+7c, SR]
[slot, 0x00, 0x04+7c, WAVE|1]    // 起音
```

## 8. 上电与调试

| 检查项 | 做法 |
|---|---|
| ① `PHI2` | SID pin8 上有干净 1 MHz（占空比接近 50%）。**这一条不对，后面全无意义** |
| ② `LE` | U2 pin1：只在 A0=0 且 /WR=0 时为高 |
| ③ `TRIG_n` | U3 pin6：空闲恒高；地址相恒高；**只有数据相写脉冲时为低** |
| ④ 无声 | 先确认写过 `0x18=0x0F`；再量 pin25=5V、pin28=12V（6581 缺 12V 完全无声） |
| ⑤ 音量寄存器写了没响 | 量 SID pin6 是否真的跟 `TRIG_n` 通断（线断了就完全写不进去） |
| ⑥ 每次起音咔哒 | pin6 是否接的是 `TRIG_n`（含 `¬A0`），而不是直接接 `CSn` |
| ⑦ 只有部分寄存器能写 | 量 U1 pin12（Q4）→ SID pin13 通断——A4 断了就只有 0x00–0x0F 能用 |
| ⑧ 地址恒 0 或随机 | 374 上电后 Q 是不定态。先写一次 `[slot,0x00,0x00,0x00]` 归零 |
| ⑨ pin8 接错 | pin8 必须接晶振，不是 `TRIG_n`。接错则完全无时钟、永远无声 |
| ⑩ 声音发乱 | 检查有没有人把 `TRIG_n` 同时接到 pin7。现在 `R/W` 必须是 SPFM 的 `/WR` 裸线 |
| ⑪ 换板后突然无声 | 先怀疑 MCU 板/线材，再怀疑接线。已出现过一块板子故障导致全无声音 |

**验收标准**：`--write-mode two-phase --repeat 1 --delay 0` 单次写入稳定出声，
`scale` 每个音高正确，`music --song twinkle` 三声部同时响。

## 10. 一句话总结

D0–D7 共享；A0 当相位；`LE = NOR(A0, /WR)` 敲 374 的上升沿；
`TRIG_n = ¬A0 ∨ /WR ∨ CSn` 只在数据相写脉冲期间拉低，**直连 SID 的 `/CS`（pin6）**；
SPFM 的 `/WR` **直连 SID 的 `R/W`（pin7）**；`PHI2` 由 1 MHz 晶振单独供给（pin8）；
主机一条 `[slot, 0x00, addr&0x1F, data]` 完成一次寄存器写。

**三颗 IC：74LS374 + 74HCT02 + 74HCT32。不用 74HC74，不用移位寄存器，不用单稳态。**
