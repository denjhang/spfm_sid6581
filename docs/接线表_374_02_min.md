# SID 6581 挂 SPFM 完整接线表 —— 实用方案：374 + 02 + 32 + 74HC74（已上机验证）

> **本方案已在实际硬件上验证成功。** 四颗 IC：74LS374 + 74HCT02 + 74HCT32 + 74HC74。
> **不需要移位寄存器**（164 / 595 / 174 / 273 全部省掉），也不需要 123 单稳态。
>
> **74HC74 不可省。** 实测：跳过它、把 `TRIG_n` 直接接 SID 的 `/CS` 和 `R/W`，
> 单次写入会出现明显失真（声音变乱）；保留它则单次写入干净稳定。
> 它在这里的作用不是"计数关窗口"，而是**整形 + 缓冲 + 轻微展宽**，见 §5。

## 1. 电路的全部内容

```
LE      = NOR(A0, /WR)                  // U2 g1 → 374 的 CLK
nA0     = NOR(A0, A0) = ¬A0             // U2 g2 → 反相器
TRIG_n  = OR(nA0, /WR, CSn)             // U4 g1 + g2
        = ¬A0 ∨ /WR ∨ CSn
nTRIG   = ¬TRIG_n                       // U2 g3（两输入并联）

// U3 = 74HC74，两个触发器都用
QW      = SR latch:  置位 = TRIG_n↓ ,  清零 = DONE_n↓
Wn      = ¬QW                           // → SID pin6 (/CS) + pin7 (R/W)
DONE_n  = SR latch:  置位 = nTRIG↓ ,   清零 = TRIG_n↓
```

展开后就是一个**跟随 `TRIG_n` 的反相器**，但带两级 FF 的整形与缓冲：

| `TRIG_n` | `nTRIG` | `DONE_n` | `QW` | **`Wn`** | SID 侧 |
|---|---|---|---|---|---|
| 高（空闲 / 地址相 / 未选中） | 低 | 低 | 0 | **1** | 释放总线 |
| **低**（数据相 + 本槽 + 写） | **高** | 高 | **1** | **0** | **`/CS` 与 `R/W` 同时为低，写入** |

## 5. 74HC74 到底做了什么（为什么不能省）

### 5.1 它不是"跟随器"，是"整形器"

逻辑上 `Wn = ¬TRIG_n`，但两者的**边沿质量完全不同**：

| 路径 | 延迟 |
|---|---|
| `TRIG_n` ↓ → `Wn` ↓ | 仅 U3A 一级，约 **18 ns** |
| `TRIG_n` ↑ → `Wn` ↑ | `TRIG_n` → U2 反相（12 ns）→ U3B 置位（18 ns）→ `DONE_n` 低 → U3A 清零（18 ns），约 **48 ns** |

结果：**`Wn` 比 `TRIG_n` 宽约 30 ns，且整体后移约 18 ns。**

`TRIG_n` 是从 U4（74HCT32）出来、驱动 3 个负载（U3 两个脚 + U2 两个脚）的普通 CMOS 输出，
边沿有一定斜率（几 ns/V），走线上还有分布电容和 10k 上拉。
SID 的 `/CS` 与 `R/W` 是在 PHI2 沿**同时**采样的，需要两个信号在那一刻都稳定为低。
斜率不陡的边沿 + 极窄的脉冲，很容易让某一次采样落在过渡区。

74HC74 把 `TRIG_n` 重新打成**满幅度、陡边沿**的 `Wn`，并且多给出 30 ns 余量。
这不是"上拉或下拉"，是**信号再生 + 缓冲**。

### 5.2 为什么拆掉就"声音很乱"

实测现象：跳过 U3，把 `TRIG_n` 直接接 SID pin6/pin7，单次写入时声音明显失真。

三个可能叠加的原因：

1. **驱动能力不足。** SID 的 `/CS` 和 `R/W` 各是一个 CMOS 输入，但两根线加起来
   加上走线电容，让 U4 一个门的上升/下降沿变慢。74HC74 的输出驱动更强。
2. **边沿变慢导致 SID 内部采样失败。** `/CS` 与 `R/W` 是同一时刻采的（见 §6.2），
   若其中一根的边沿落后另一根，可能采到"一个低一个高"，这一笔就成了非写非读的中间态。
   经过 FF 后两者来自**同一个输出脚**，物理上完全不可能错开。
3. **毛刺。** SPFM 的 CSn / /WR 上有 10k 上拉，总线切换时可能出现窄毛刺。
   经过 FF 的两级异步端，窄毛刺要么被吃掉、要么被整形成干净脉冲。

**不管哪一条为主，结论是实测确定的：U3 必须保留。**

### 5.3 那么把 `TRIG_n` 直接接 SID 为什么"也能出声"

直接接能让 SID 收到写操作，所以能出声——但窗口太紧，单次写入的成功率不稳定，
表现为音色失真、音高偶发错误。用 `--repeat` 多次重写能掩盖一部分，但那是靠冗余撞运气。

保留 U3 后窗口由 FF 重新给出，单次写入干净。**这就是为什么"能出声"和"声音正确"是两件事。**

> **pin 8 是 `PHI2`，不是 `Wn`。** 若把 pin 8 接到 `Wn`，SID 就没有时钟，
> 内部振荡器、包络、寄存器扫描全停，一颗音都发不出来。

`Wn` 一个 FF 输出带 SID 的 `/CS` 和 `R/W` 两个 CMOS 输入，74HC 扇出足够。
**这一点很关键**：两者接同一个脚，物理上不可能有偏斜。

### 6.1 为什么 `/CS`（pin6）和 `R/W`（pin7）必须接同一根线

6581 的写条件是三个条件**同时成立**：

```
/CS = 0  ∧  R/W = 0  ∧  PHI2 出现有效沿
```

前两个我们能控，第三个控制不了——`PHI2` 是 SID 自己的自由振荡时钟，和 SPFM 总线没有相位关系。

**依据一：datasheet 的 `TW` 定义**

```
TW  Write Pulse Width  min 350 ns
    "TW is measured from the latest occurring of φ2, CS, R/W"
```

"从 φ2、CS、R/W 三者中**最晚**发生的那一个开始算"——三者并列、缺一不可。

**依据二：reDIP-SID 的写条件**（`gateware/sid_control.sv`）

```systemverilog
w = ~bus_i.phi2 & ~bus_i.r_w_n && voice_cycle >= 1 && voice_cycle <= 6;
...
end else if (cycle_cs && w && vaddr >= 0 && vaddr <= 6) begin
    v0.bytes[vaddr[2:0]] <= bus_i.data;
```

**依据三：两者由同一个时钟沿采样**（`gateware/sid_io.sv`）

```systemverilog
phi1_io = ~phi2_io;
...
) io_r_w_n ( .LATCH_INPUT_VALUE (phi1_io), .D_IN_0 (bus_i.r_w_n) );
) io_cs    ( .LATCH_INPUT_VALUE (phi1_io), .D_IN_0 ({ cs }) );
```

`/CS` 和 `R/W` 都在 `phi1`（φ2 反相）沿被锁存，**采样时刻完全相同**。
既然同一时刻采两个信号，就必须保证那一刻两个都是低。接成同一根线是这一要求的最强形式：
偏斜为零。

### 6.2 旧接线（`接线表_374_02.md`）到底差在哪

```
/CS_sid = OR(CSn, LE)      // 穿过两个 NOR 门
R/W     = /WR              // 裸线，直连
```

两处缺陷：

1. **不同源、有偏斜。** `/CS` 走两个 NOR 门（约 15–25 ns），`R/W` 是裸线。
   SID 在同一个沿采这两个信号，边沿错开就可能采到不一致的组合。
2. **`/CS` 在两相之间一直是低的。** 地址相结束、`LE` 落下后，`/CS` 立刻变低并保持到数据相结束，
   期间 SID 处于"半个写状态"，任何 D 线上的过渡都可能被当成数据。

现在 `TRIG_n` 经 U3 再生为 `Wn`，同时驱动两个脚：边沿完全重合、空闲期彻底干净。

## 7. 主机侧写入序列

走固件**路径 A**（4 字节）：

```
[slot, 0x00, addr & 0x1F, data]
```

| 步骤 | 固件动作 | 总线上 | 结果 |
|---|---|---|---|
| 1 | A0=0，D=`addr&0x1F`，/WR 脉冲 | `LE` 上升沿 | 374 捕获 A0–A4；`TRIG_n`/`Wn` 保持高 |
| 2 | A0=1，D=`data`，/WR 脉冲 | `TRIG_n` 低 → `Wn` 低 | SID 的 /CS 与 R/W 同时拉低，写入 |

**`0x1F` 掩码不能省**（保证地址字节 bit7=0）。

**不要照抄原 midi.c 用 374 的 Q7 驱动 R/W。** 那样 R/W 的窗口缩回 `/WR` 宽度，
而且和 `/CS` 又变成不同源、有偏斜，等于把本方案改回旧接线。Q7 空着。

### 7.1 初始化

复位后 volume（0x18）= 0，**不写就没有声音**：

```
[slot, 0x00, 0x18, 0x0F]    // volume = 15
[slot, 0x00, 0x17, 0xF0]    // 谐振 + 滤波通道使能（按需）
[slot, 0x00, 0x16, CUTOFF]  // 截止频率（按需）
```

### 7.2 一个音符

```
[slot, 0x00, 0x00+7c, freq_lo]
[slot, 0x00, 0x01+7c, freq_hi]
[slot, 0x00, 0x05+7c, AD]
[slot, 0x00, 0x06+7c, SR]
[slot, 0x00, 0x04+7c, WAVE|1]    // 起音
```

## 8. 上电与调试

| 检查项 | 做法 |
|---|---|
| ① `PHI2` | SID pin8 上有干净 1 MHz（占空比接近 50%）。**这一条不对，后面全无意义** |
| ② `LE` | U2 pin1：只在 A0=0 且 /WR=0 时为高 |
| ③ `TRIG_n` | U4 pin6：空闲恒高；地址相恒高；**只有数据相写脉冲时为低** |
| ④ `nTRIG` | U2 pin10：与 `TRIG_n` 严格反相，边沿紧跟（约 12 ns） |
| ⑤ `Wn` | U3 pin6：与 `TRIG_n` 反相，**下降沿紧跟（约 18 ns），上升沿落后约 48 ns** |
| ⑥ `Wn` 恒低 | U3 pin1 被拉低。量 U3 pin8 是否恒低 → 说明 U3B 没被 `TRIG_n` 清掉，查 pin13 |
| ⑦ `Wn` 恒高 | U3 pin4 悬空或接错。**悬空的 CMOS 输入电平不确定**，必须接 `TRIG_n` |
| ⑧ 声音失真（本方案要解决的） | 确认 U3 在位、`Wn` 取自 pin6（不是 pin5）、pin1/pin13 都接好了 |
| ⑨ 无声 | 先确认写过 `0x18=0x0F`；再量 pin25=5V、pin28=12V（6581 缺 12V 完全无声） |
| ⑩ 只有部分寄存器能写 | 量 U1 pin12（Q4）→ SID pin13 通断——A4 断了就只有 0x00–0x0F 能用 |
| ⑪ 每次起音咔哒 | SID pin6 是否接 U3 pin6，而不是直连 CSn（直连会在地址相和空闲期误写） |
| ⑫ 地址恒 0 或随机 | 374 上电后 Q 是不定态。先写一次 `[slot,0x00,0x00,0x00]` 归零 |
| ⑬ pin8 接错 | pin8 必须接晶振，不是 `Wn`。接错则完全无时钟、永远无声 |
| ⑭ 拆 U3 后立刻坏了 | **正常现象**。`TRIG_n` 直接驱动 SID 会失真，U3 不可省（见 §5） |

**验收标准**：`--write-mode two-phase --repeat 1 --delay 0` 单次写入稳定出声，
`scale` 每个音高正确。做到这两条，`--repeat` 可以从驱动默认值撤到 1。

## 9. 与"计数拉宽窗口"四份方案的关系

之前从 reDIP-SID 的 RTL 推断"写必须落在内部 18 周期轮转的第 1–6 周期"，
需要 ≥12 µs 的窗口，设计了用 PHI2 计数把窗口拉宽到 13–14 µs 的电路：

| 方案 | 追加器件 | 窗口 | 文件 |
|---|---|---|---|
| 74HC164 ×2 | 2 片 | 13–14 µs | [接线表_374_02_74_164.md](接线表_374_02_74_164.md) |
| 74HC595 ×2 | 2 片 | 13–14 µs | [接线表_374_02_74_595.md](接线表_374_02_74_595.md) |
| 74174 ×3 | 3 片 | 13–14 µs | [接线表_374_02_74_174.md](接线表_374_02_74_174.md) |
| 74273 ×2 | 2 片 | 13–14 µs | [接线表_374_02_74_273.md](接线表_374_02_74_273.md) |

**实测证明这个推断过于保守**：真实 6581 只需"`/CS` 与 `R/W` 同时为低、质量足够好"就能写入，
不需要 13 µs 的窗口。那 18 周期轮转是芯片内部的写调度，不是总线侧必须满足的时序条件。

四份文件保留作为备选：如果将来换机器、换固件版本后出现偶发丢音，
把它们接上（`TRIG_n` 改接 74HC74 的 `1/PRE`，`Wn` 照旧驱动 SID）即可。

**教训：FPGA 软核 RTL 用于理解芯片行为，但硬件时序以实测为准。**

## 10. 一句话总结

D0–D7 共享；A0 当相位；`LE = NOR(A0, /WR)` 敲 374 的上升沿；
`TRIG_n = ¬A0 ∨ /WR ∨ CSn` 只在数据相写脉冲期间拉低；
**再经过 74HC74 整形缓冲得到 `Wn`，同时驱动 SID 的 `/CS`（pin6）和 `R/W`（pin7）**；
`PHI2` 由 1 MHz 晶振单独供给（pin8）；
主机一条 `[slot, 0x00, addr&0x1F, data]` 完成一次寄存器写。

**四颗 IC：74LS374 + 74HCT02 + 74HCT32 + 74HC74。不用移位寄存器，不用单稳态。**
