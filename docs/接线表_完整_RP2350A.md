# 完整接线表 —— RP2350A + 2× 74LVC245 + 374/02/32 + SID 6581

> 2026-11-25。这是**现在实际要焊的**那一份，替换掉 SPFM 时代的接线。
> 旧接线（SPFM 总线直连）仍保存在 [接线表_374_02_min.md](接线表_374_02_min.md)，已上机验证过，可作对照。
>
> **变化只有电源和接口这两端**：SID 那侧的 374 + 02 + 32 逻辑一个字没改，
> 中间从"SPFM 总线排针"换成"RP2350A → 两颗 74LVC245 → 同样的信号名"。
> 所以旧文档里的 `LE` / `TRIG_n` 真值表和 SID 引脚表原样有效。

---

## 0. 三层结构

```
RP2350A (3.3V)          U1/U2 74LVC245          374/02/32 (5V)        SID 6581
──────────────          ──────────────          ──────────────        ────────
GPIO0-7   D0-D7  ──►  U1 ──────────────────►  D0-D7 ──────────────► D0-D7
GPIO11    DIR    ──►  U1 pin1
GPIO8     WR#    ──►  U2 ──────────────────►  /WR  ──┬────────────► R/W (pin7)
GPIO9     /RD    ──►  U2                     (不接)  ├─ U2 pin3
GPIO10    A0     ──►  U2 ──────────────────►  A0   │  └─ U3 pin2
GPIO12    CS0#   ──►  U2 ──────────────────►  CSn  └─ U3 pin5
GPIO21    IC#    ──►  U2 ──────────────────►  IC ────────────────► /RES (pin5)
GPIO14    PHI2   ───────────────────────────────────────────────► PHI2 (pin8)
GPIO16    WS2812（板载，不接出去）
```

**PHI2 不经 245**：它从 MCU 出来直接到 SID pin8，是唯一一条绕过缓冲的信号。

| 引脚 | 名称 | 接到 | 备注 |
|---|---|---|---|
| 1 | 1Y | **U3 pin11（CLK）** | `LE = NOR(A0, /WR)` |

### 5.2 U5 —— 74HCT32（4 OR，用 2 个）

| 引脚 | 名称 | 接到 | 备注 |
|---|---|---|---|
| 1 | 1A | **U4 pin4（`nA0`）** | |
| 2 | 1B | **/WR** | |
| 3 | 1Y | **U5 pin4** | `t = OR(¬A0, /WR)` |
| 4 | 2A | **U5 pin3** | |
| 5 | 2B | **CSn** | 低有效 |
| 6 | 2Y | **SID pin6（/CS）** | **`TRIG_n`，直连，不经过缓冲** |
| 7 | GND | GND | |
| 8, 9, 10 | 3A, 3B, 3Y | **3A、3B 接 GND** | 闲置门输入接地 |
| 11, 12, 13 | 4Y, 4A, 4B | **4A、4B 接 GND** | 闲置门输入接地 |
| 14 | VCC | **+5V**，旁挂 100nF | |

三条逻辑，和旧接线一字不差：

```
LE      = NOR(A0, /WR)                  → U3 pin11
nA0     = NOR(A0, A0) = ¬A0             → U5 pin1
TRIG_n  = OR(nA0, /WR, CSn) = ¬A0 ∨ /WR ∨ CSn   → SID pin6
```

真值表（仍然有效）：

| `A0` | `/WR` | `CSn` | `LE` | `TRIG_n` | SID `R/W` | SID 侧 |
|---|---|---|---|---|---|---|
| x | 1 | x | 0 | 1 | 1 | 释放 |
| 0 | 0 | 0 | **1** | **1** | 0 | 374 抓地址；`/CS` 高，SID 不响应 |
| **1** | **0** | **0** | 0 | **0** | **0** | **写入** |
| x | x | 1 | x | 1 | x | 不选中 |

**CS0# 由 GPIO12 常拉低**（整场有效），所以 `TRIG_n` 实际由 `A0` 和 `/WR` 决定。

## 6. PHI2 —— PIO 生成，不需要晶振（已上机验证）

| 从哪里 | 到哪里 | 说明 |
|---|---|---|
| **GPIO14** | **SID pin8** | PIO 生成的 985 248 Hz 方波，**直连**，不分压不串阻（MCU 输出 3.3 V，SID 的 VIH 是 2.0 V） |

2026-11-25 实测：GPIO14 直接接 SID pin8 就能工作。PIO 程序用
USBSID-Pico 的 `set pins` 写法（不是 sideset）。

- 频率：PAL 985 248 Hz（libsidplayfp 用的主时钟），NTSC 1 022 727 Hz 由 `CMD_PHI2` 切换
- 分频：150 MHz ÷ (2 × 985 248) = 76.123，PIO 落在 985 272 Hz，**+24.6 ppm = 0.04 音分**
- GPIO14 是纯输出，不反馈回 MCU

> 旧方案里 PHI2 是 1 MHz 晶振；换成 985 248 Hz 后每首 PAL 曲子不再高 25.7 音分。
> 原文档 §6 说"8580 用 0.985 MHz"——6581 其实也一样用 985 248。

## 9. 上电检查顺序

| 顺序 | 检查项 | 判断 |
|---|---|---|
| ① | U1/U2 pin20 = 3.3V，pin19 = 0V | 不满足就别往下量 |
| ② | U2 pin1 = 3.3V | DIR 焊死，不能悬空 |
| ③ | U1 pin1 = 3.3V | 写方向 |
| ④ | **GPIO14 有 985 kHz 方波，峰值 ≈3.3 V** | 没有就是 PIO 没起或脚没接 |
| ⑤ | U3 pin11（LE）只在 A0=0 且 /WR=0 时为高 | |
| ⑥ | U5 pin6（TRIG_n）空闲恒高，只有数据相写脉冲时为低 | 地址相必须为高 |
| ⑦ | SID pin25 = 5V、pin28 = 12V | 缺 12V 完全无声 |
| ⑧ | 写 `0x18=0x0F` 后量 pin27 有直流偏移 | 音量生效 |

## 10. 一句话

**D0–D7 和所有控制信号都过 245（U1 双向、U2 单向），PHI2 直接从 GPIO14 进 SID pin8；
SID 那侧的 374 + 02 + 32 三条逻辑和旧接线完全相同。**
