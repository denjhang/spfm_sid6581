# SID 6581 接 SPFM：74LS374 + 74HCT02 接线表（旧版）

> **⚠ 本文是最早的接线，写时序有问题（`/CS` 与 `R/W` 不同源，且 `/CS` 在两相之间恒低）。**
> 现行方案是 [接线表_374_02_min.md](接线表_374_02_min.md)（三颗 IC）。
> 本文仅作为「问题从哪里来」的历史记录保留。

## 1. 器件

| 位号 | 型号 | 作用 | 封装 |
|---|---|---|---|
| U1 | **74LS374** | 8 位 D 触发器，锁 A0–A4 | DIP-20 |
| U2 | **74HCT02** | 4 个 NOR，造 CLK 与 /CS（用 3 个） | DIP-14 |
| Y1 | 1MHz 有源晶振（8580 用 0.985MHz） | SID PHI2 | — |
| — | 100nF ×3、10µF ×1 | 去耦、音频耦合 | — |
| — | 2n2 ×2 | SID 滤波电容 | — |

全部器件由 5 V 总线驱动，LS / HC / HCT 后缀可混用，只注意每颗 100nF 去耦。

## 2. SPFM 单槽 → 模块

| SPFM 信号 | 接到 | 说明 |
|---|---|---|
| **D0–D7** | U1 的 D0–D7 **＋** SID 的 D0–D7（同网） | 地址相放 `addr & 0x1F`，数据相放 data |
| **A0** | U2 pin2（1A） | 相位位：0 = 地址相，1 = 数据相 |
| A1 / A2 / A3 | 不接 | |

| **/WR** | U2 pin3（1B）**＋** SID pin7（R/W） | 一根线两用 |

## 6. 时序

| A0 | /WR | CSn | LE (CLK) | /CS_sid | 动作 |
|---|---|---|---|---|---|
| 0 | 1 | x | 0 | 1 | 空闲 |
| **0** | **0↓** | 0 | **↑** | 1 | **地址相：374 捕获 addr，SID 未选中** |
| 0 | 0 | 0 | 1 | 1 | 地址相持续 |
| 0 | ↑ | 0 | ↓ | 1 | 地址相结束，374 保持 |
| **1** | **0** | 0 | 0 | **0** | **数据相：SID 采样 D0–D7** |
| 1 | ↑ | 0 | 0 | 1 | 写入完成 |

374 在 `/WR` 下降沿捕获地址。此时 A0=0、D 线为 `addr`，稳定。

## 7. 主机侧写入

固件**路径 A**（4 字节）：

```
[slot, 0x00, addr & 0x1F, data]
```

固件自动展开两次 BusWrite：

| 步骤 | 总线 | 结果 |
|---|---|---|
| 1 | A0=0, D=`addr&0x1F`, /WR 脉冲 | 374 捕获 A0–A4 |
| 2 | A0=1, D=`data`, /WR 脉冲 | SID 写入 |

`0x1F` 掩码不可省。

## 8. 协议参考

### 8.1 SPFM 字节流

第 1 字节 = slot(0–3)；特殊值 `0x80` = NOP 延时、`0xFE` = 全局复位。

第 2 字节高 4 位选路径：

| 第2字节 | 路径 | 字节数 | 行为 |
|---|---|---|---|
| `0x00–0x0F` | **A** | 4 | `BusWrite(N, addr)` → `BusWrite(N\|1, data)` |
| `0x20–0x2F` | SN76489 | 3–6 | 只写数据总线 |
| `0x80–0xFF` | **B** | 3 | 单次 `BusWrite(N, data)` |

N 的 bit0–3 直接映射 A0–A3。路径 A 第二次写强制 `A0=1`。

SID 走路径 A 的原因：它与 AY8910 总线层同构（A0 选地址/数据），路径 A 正好产生这两相。

### 8.2 总线特性

| 项目 | 数值 |
|---|---|
| 波特率 | 1.5 Mbps，8N1 = **10 bit/字节** |
| 线速 | 150000 B/s = 6.667 µs/字节 |
| 路径 A | 4 字节 = **26.67 µs**/寄存器 |
| 线速上限 | 37500 条 Path A/s（Path B 3 字节 = 50000 条/s） |
| 实际吞吐 | 取决于每批多少条，见 §8.3 |
| USB 抖动 | 0–125 µs（1.1 FS micro-frame） |

> 旧版本这里写"≈21 µs/寄存器、约 4 万次/s"，那是把 8N1 当成 8 bit/字节算的。
> 正确值是 10 bit/字节：4 字节 = 26.67 µs，线速上限 37500 条/s。

### 8.3 每批的条数比线速更重要

每次 `spfm_flush()` 之后，FTDI 的 2 ms latency timer 会让线路空转，
所以可持续吞吐 ≈ 批字节数 / (线上时间 + 2 ms)：

| 每批 | 线上时间 | +2 ms | 折算 | 对应场景 |
|---|---|---|---|---|
| 4 B（1 条） | 0.03 ms | 2.03 ms | 493 条/s | 每条都 flush |
| 1024 B（256 条） | 6.83 ms | 8.83 ms | 29000 条/s | ADPCM V0 / node-spfm |
| 4096 B（1024 条） | 27.31 ms | 29.31 ms | 34900 条/s | ADPCM V1 |
| 65536 B | 436.9 ms | 438.9 ms | 37300 条/s | 缓冲区满 |

折成 kB/s 的硬上限：**数据 37.5 kB/s / 线上 150 kB/s**（一条命令只带一个数据字节，
线上字节是数据字节的 4 倍）。V1 一次 4096 字节切片达到 37.3 kB/s，V0 的 256 字节/批
只有 29.0 kB/s——差额全部来自每批固定付的 2 ms。逐档表见
`docs/MDPlayer硬体写入链路考察.md` §8.1.1。

参照系是 `Denjhang_Music_Player_v16` 的 YM2608 ADPCM 预载——零节流整块灌数据，
是这套硬件上唯一上机验证过的"全速写入"路径。`sidtest bench` 在本机复现它的
V0/V1 两种形状，直接给出实测值。

16 根总线全是协议信号，**没有 GPIO**。`/RD`、`IC` 即使本模块不用也不能挪用为地址位或模式脚。

复位只有全局 `0xFE`，不能按槽控制。SID 场景影响不大（初始化反正要重写音量）。

## 9. 初始化与播放

### 9.1 必须先写音量

复位后 volume（0x18）= 0，**不写完全没声音**：

```
[slot, 0x00, 0x18, 0x0F]     // volume = 15
[slot, 0x00, 0x17, 0xF0]     // 谐振 + 滤波通道（按需）
[slot, 0x00, 0x16, CUTOFF]   // 截止频率（按需）
```

### 9.2 寄存器图

| 地址 | 声部1 | 声部2 | 声部3 | 功能 |
|---|---|---|---|---|
| +0 | 0x00 | 0x07 | 0x0E | 频率低 8 位 |
| +1 | 0x01 | 0x08 | 0x0F | 频率高 8 位 |
| +2 | 0x02 | 0x09 | 0x10 | PWM 低 |
| +3 | 0x03 | 0x0A | 0x11 | PWM 高（4 位） |
| +4 | 0x04 | 0x0B | 0x12 | 控制（gate/波形/ring/sync） |
| +5 | 0x05 | 0x0C | 0x13 | Attack / Decay |
| +6 | 0x06 | 0x0D | 0x14 | Sustain / Release |

| 地址 | 功能 |
|---|---|
| 0x15 | 滤波器截止低 3 位 |
| 0x16 | 滤波器截止高 8 位 |
| 0x17 | 谐振 + 滤波通道使能 |
| 0x18 | bit7=断开声部3、bit6=高通、bit5=带通、bit4=低通、bit3–0=音量 |

控制寄存器波形位：bit4=三角、bit5=锯齿、bit6=方波、bit7=噪声，bit0=gate。

0x18 的 bit4–7 **不是波形开关**，是滤波器模式（低通/带通/高通）和声部 3 静音。
`0x18 = 0x1F` = 低通 + 音量 15；`0x18 = 0x0F` = 不滤波 + 音量 15。

### 9.3 一个音符

```
[slot, 0x00, 0x00+7c, freq_lo]
[slot, 0x00, 0x01+7c, freq_hi]
[slot, 0x00, 0x05+7c, AD]
[slot, 0x00, 0x06+7c, SR]
[slot, 0x00, 0x04+7c, WAVE|1]    // 起音
```

释放：`[slot, 0x00, 0x04+7c, WAVE]`（gate 清零）。

### 9.4 频率换算

SID 频率寄存器 = `f_out × 16777216 / PHI2`。1MHz 下：

| 音符 | 频率寄存器 |
|---|---|
| A4 (440Hz) | ≈7382 |
| C4 (261.6Hz) | ≈4389 |
| A2 (110Hz) | ≈1845 |

参考 `arduino_sid/midi.c` 里的 `freq[]` 表（1MHz 标定，MIDI note 12–108）。

## 10. 调试

| 症状 | 检查 |
|---|---|
| 完全无声 | 先确认写过 `0x18=0x0F`；量 Y1 输出有 1MHz；量 pin25=5V、pin28=12V |
| 只有 0x00–0x0F 能写 | 量 U1 pin12 (Q4) → SID pin13 通断（A4 断了） |
| 起音每次都咔哒 | SID pin6 必须接 U2 pin10，不能直连 CSn（地址相会误写 gate=0） |
| 写入地址错位 | 量 U2 pin1 是否**只在 A0=0 且 /WR=0 时为高** |
| 地址恒 0 或随机 | 374 上电不定态。先写一次 `[slot,0x00,0x00,0x00]` 归零 |
| 音量写了没反应 | 6581 缺 12V 时完全无声；8580 是 9V，别接错 |

## 11. 未使用/禁止事项

| 项 | 说明 |
|---|---|
| A1–A3 | 不接。A0 已被用作相位位，其余地址线无意义 |
| /RD | 不接。总线读选通，不可挪用 |
| Q5–Q7 | 不接。Q7 不再像原 midi.c 那样锁 R/W（我们直连 /WR） |
| U2 pin11–13 | 第 4 门闲置，输入必须接地 |
| 直连 CSn 到 SID | 禁止。地址相会写入垃圾值，导致 ADSR 反复重启 |
| LE 接 /WR 或 /CS | 禁止。两者整周期有效，锁存器会全程透明 |
