# RP2350A 引脚分配（SID 控制器）

> 2026-11-25。板子：淘宝 RP2350A 核心板，引出 GPIO0–GPIO28（GPIO29 是 VSYS/ADC3）。
> 依据 [RPFM/docs/GPIO_PINOUT.md]、[RPFM/docs/WS2812_LED.md]、[RPFM/docs/PERIPHERALS_PLAN.md]
> 和 RPFM 的 `src/rpfm/main.c`，并用 `led_test` 上机实测校正过板载 LED 引脚。

## 0. 上机实测结论（2026-11-25）

| 结论 | 怎么测的 |
|---|---|
| **板载 WS2812 在 GPIO16** | `led_test` 分别只驱动 GPIO16 和 GPIO22：驱动 22 时 4 颗灯全灭，驱动 16 时流水灯正常。**22 上没有灯。** |
| GPIO25 是板载单色心跳灯 | 250 ms 翻转，肉眼可见 |
| WS2812 是 4 颗串联 | 必须每次发 4 帧；只发 1 颗其余不受控 |
| 亮度 | 0x18 左右不刺眼；RPFM 片选指示用 ~40%（0x66） |

**RPFM 的 `main.c` 里 `PIN_WS2812` 写的是 22，那是错的。** 那是 commit `3cf1d8b`
（"外设扩展：PIO 总线精简 + I2C 屏幕驱动"）为了把 GPIO16 让给 I2C 屏的 SCL 才改的，
文档没跟着改。本机这块板上 22 是空的，照抄 `main.c` 会得到一盏全灭的灯。

## 1. 板上已经被硬件占死的脚（不许动）

| GPIO | 用途 | 出处 |
|---|---|---|
| **16** | 板载 WS2812，4 颗 RGB 串联，PIO 800 kHz 驱动 | `WS2812_LED.md` + **本机实测确认** |
| **25** | 板载心跳 LED | `pico2.h` `PICO_DEFAULT_LED_PIN 25`，实测 |

**这两个脚不能拿来当总线用。** 呼吸灯/彩灯指的就是这两处：
GPIO16 是 WS2812 彩灯串，GPIO25 是单色心跳灯（亮度靠占空比调）。

## 2. 需要避开的脚（不是硬件占用，是启动/电源相关）

| GPIO | 原因 |
|---|---|
| 23 | `PICO_SMPS_MODE_PIN`，上电时决定稳压器模式，拉错会改供电行为 |
| 24 | `PICO_VBUS_PIN`，VBUS 检测 |
| 29 | `PICO_VSYS_PIN`，VSYS 分压检测（也是 ADC3） |

这三个只在板子沿用 Pico 2 参考设计时才需避开。我们的方案用不到它们，直接空着最省事。

## 3. 我们真正需要的信号

SID 挂在 SPFM 总线上，主机只能发 Path A（`[slot,0x00,addr,data]`），
固件把它展开成两次 BusWrite。所以总线侧只需要：

| 信号 | 位数 | 必需? | 说明 |
|---|---|---|---|
| D0–D7 | 8 | 必需 | 数据 → 74LVC245 → SID D0–D7 |
| A0 | 1 | 必需 | 区分地址相/数据相，`LE = NOR(A0,/WR)`、`TRIG_n = ¬A0∨/WR∨CSn` 都靠它 |
| WR# | 1 | 必需 | 接 SID `R/W`（裸线直连，见交接文档 §0.4） |
| CS0# | 1 | 必需 | 本槽片选 |
| RD# | 1 | 可选 | 只有将来加 74xx245 双向缓冲、要读 `$D41B/$D41C` 时才需要 |
| A1/A2 | 2 | 可选 | 留给第二颗 SID 或别的芯片，A1 还能区分 YM2608 的 FM/SSG |
| PHI2 输出 | 1 | 新增 | **PIO 生成** 985 248 Hz，直接进 SID pin8 |
| IC# | 1 | 必需 | 全局复位 |

**PHI2 由 MCU 的 PIO 生成**（2026-11-25 上机验证）。原先的设计用外部晶振、
MCU 只做输入，理由是"MCU 挂了时钟就停"；但没有 0.985 MHz 的晶振，而 PIO 的
分频精度是 +24.6 ppm（0.04 音分），直接输出更好，也省掉分压电阻。

## 4. 最终分配

沿用 RPFM 已验证的布局，只把 PIO 总线后面空出来的第一个脚给 PHI2。

| GPIO | 功能 | 方向 | 备注 |
|---|---|---|---|
| **0–7** | D0–D7 | 双向 | → U1 LVC245；`out pins,8` 要求连续 |
| **8** | WR# | 输出 | → U2 → SID `R/W` |
| **9** | /RD | 输出 | → U2；读回预留 |
| **10** | A0 | 输出 | → U2；地址相/数据相 |
| **11** | **DIR** | 输出 | **U1 pin1**；1=写（A→B），0=读（B→A） |
| **12** | CS0# | 输出 | 只用一个片选（经 U2） |
| **14** | **PHI2** | **输出** | **PIO 生成 985 248 Hz（PAL），不用晶振** |
| **16** | WS2812 | 输出 | **板上固定，勿动（实测确认）** |
| **21** | IC# | 输出 | 全局复位（经 U2） |
| **25** | 板载 LED | 输出 | 心跳，板上固定 |

**A1/A2 不用**（只有一颗 SID），所以 PIO 总线是 11 位而不是 13 位。
接线细节见 [接线_MCU侧_LVC245.md](接线_MCU侧_LVC245.md)。

空闲：13、15、17、18、19、20、22、26、27、28（23/24/29 是 SMPS_MODE / VBUS / VSYS，空着）。

## 5. PIO 资源

| PIO | SM | 用途 | 引脚 |
|---|---|---|---|
| PIO0 | SM0 | 11-bit 总线（D0–7 / WR# / RD# / A0） | 0–10 连续 |
| PIO1 | SM0 | WS2812 | 16 |
| PIO0 | SM1 | **PHI2 生成**（`phi2_gen`） | 14 |

**片选不再走 PIO**：只有一颗 SID，CS0# 用 `gpio_put(GPIO12, 0)` 常有效即可，
省掉一个 PIO 状态机（RPFM 原来用 PIO1 SM1 输出 CS0/CS1 两个脚）。
CS 常低是可以的——SID 的 `/CS` 在这里已经不是"片选"，而是 `TRIG_n` 的一部分，
真正的写条件由 `¬A0 ∨ /WR ∨ CSn` 决定（见交接文档 §1）。

PHI2 用独立 SM，两条 `set pins` 指令一个周期，不跟总线 SM 抢。

**同一组引脚只能有一个 SM。** RPFM 原文会额外起一个 AY8910 SM，同一个程序抢
同一组 GPIO0–10，A0 被盖成 0——这是调试期最大的坑。

## 6. 和 RPFM 现有固件的差异（要改的地方）

| 项目 | RPFM 现值 | 我们的值 | 原因 |
|---|---|---|---|
| `PIN_WS2812` | 22 | **16** | **实测：22 上无灯，16 才有**。RPFM 那个 22 是给 I2C 屏让位改的 |
| `PIN_BUS_BASE` / 位宽 | 0 / 13 位 | 0 / **11 位** | A1/A2 不用 |
| `PIN_CS_BASE` | 13（PIO1，2 位） | **GPIO12 单脚，常低** | 只有一颗 SID |
| `PIN_DIR` | 无 | **GPIO11** | 两颗 LVC245 需要方向控制 |
| `PIN_PHI2` | 无 | **GPIO14 输出** | PIO 生成 PAL/NTSC 时钟 |
| `PIN_IC` | 21 | 21 | 不变 |
| `PIN_LED` | 25 | 25 | 不变 |
| I2C 屏（`lcd.c`，SDA15/SCL16） | 启用 | **不编译** | SCL16 就是 WS2812，冲突 |

## 7. 已经不存在不确定项

板上 LED 引脚由 `led_test` 实测定论：**WS2812 = GPIO16，心跳 = GPIO25**，
GPIO22 空。这一条不需要再猜或再查文档。

23/24/29 是否真按 Pico 2 的 SMPS_MODE / VBUS / VSYS 用，仍建议看一眼板子丝印，
但无论如何我们都空着它们，不构成风险。
