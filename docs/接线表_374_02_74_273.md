# 方案 D：74273 ×2（8 位并行 D 触发器）

> 共用部分（U1 74LS374、U2 74HCT02、U3 74HC74、U4 74HCT32、译码方程、
> 主机侧写入序列、调试）见 [接线表_374_02_74.md](接线表_374_02_74.md)。
> **本文只写移位链这一段。**

## 1. 追加器件

| 位号 | 型号 | 作用 |
|---|---|---|
| U5 | 74HC273 / 74273（8 位 D-FF，带 /CLR） | 计数链第 1–8 级 |
| U6 | 74HC273 / 74273 | 计数链第 9–16 级 |
| — | 100nF ×2 | 每片一颗去耦 |

两片就够 16 级，比 74174 少一片，级数还富余。**如果手上有 74273，这个方案比 174 省事。**

## 2. 用 D-FF 搭移位链的原理

74273 是**并行** D 触发器：8 个触发器共用一个时钟，各自的 D 独立。
把它接成移位链只需要把每级的输入接到前一级的输出：

```
U5:  D0 ← U3.Q          U6:  D0 ← U5.Q7
     D1 ← U5.Q0              D1 ← U6.Q0
     D2 ← U5.Q1              D2 ← U6.Q1
     ...
     D7 ← U5.Q6              D7 ← U6.Q6
```

所有片的 `CLK` 接同一根 PHI2。片内 `Q→D` 的连线是芯片内部走线，
同一时钟沿上每级拿到的是**上一拍**的前级值，所以这就是标准移位链。

**片间连一根线**：U6 的 D0 接 U5 的 Q7。

## 4. 抽头

14 级 = U5 的 8 级 + U6 的前 6 级，所以 **tap = U6 pin15（Q5）**。
接 U2 的 3A（pin8）和 3B（pin9）并联，U2 的 3Y（pin10）输出 `nTAP` 接 U3 pin10（2/PRE）。

## 5. 接线注意事项

1. **两片的 `CLK` 必须是同一根 PHI2**，从 Y1 输出各自引线，不要串接。
2. **两片的 `/MR` 必须并在一起接 U3 pin8**。如果只清一片，另一片会残留旧数据，
   下一轮的 1 会和残留叠加，tap 提前变高、窗口变短。
3. **74273 没有 Q̄ 输出**，只能取 Q。本设计本来也只用 Q。
4. **74273 的 /MR 是异步的**（不像 377 那种同步清零），所以 §7 的"直接硬清零"成立。
   如果你的件是 **74377**（同步清零），本方案不成立——74377 的清零要等一个时钟沿，
   窗口会多一个周期，而且清零时机不可控。买件时认准 **273**。
5. **上电时 /MR 要能拉高**。若 U3 上电不定态导致 `/MR` 持续为低，链不工作——
   写一次任何寄存器即恢复正常。

6. **为什么分立 D-FF 串链不会"追尾"**：每级 `D` 来自前一级 `Q`，两者同一个时钟沿动作。
   这要求前级 `Q` 的传播延迟（`tpd`，74HC 在 5 V 下约 13–25 ns）大于后级 `D` 的保持时间
   （约 5 ns），否则新值会在旧值被采到之前就冲掉。74HC273 / 74273 都满足，
   这也是它能在 1 MHz 下稳定工作 100 倍余量的原因。**但不要用极快的 74AC/74AHC 混搭慢速级**，
   同型号整批用最省心。

## 6. 调试

| 现象 | 检查 |
|---|---|
| 链完全不动 | 某片 `CLK`（pin11）没接到 PHI2 |
| 只有 U5 会动 | 级联断了：量 U5 pin19 → U6 pin3 |
| tap 在第 8 级就变高 | U6 的 D0 接错（接到了 U5 的 Q6 而不是 Q7） |
| 窗口约 15–16 µs | tap 取到了 U6 pin19，改到 U6 pin15 |
| 某一片的输出全为 0 | 该片 `/MR`（pin1）被拉低，或 VCC/GND 没接 |
| 窗口每次都不一样且波动 > 1 µs | CLK 上有毛刺。PHI2 是晶振方波，正常不会有；检查走线是否与 /WR 并行过长 |
