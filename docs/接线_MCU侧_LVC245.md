# MCU 侧接线（RP2350A + 2× 74LVC245）

> 2026-11-25。前提：片选只用一片（CS0#），A1/A2 不用。
> 两颗 LVC245 夹在 **RP2350A 和 SPFM 总线排针之间**，
> 不是夹在总线与 SID 之间——SID 那侧的 374 + 02 + 32 接线不变。

## 1. 先定方向（74LVC245 引脚语义）

```
74LVC245（DIP/SOIC 20 脚）
  pin 1  DIR      H: A→B    L: B→A
  pin19  /OE      L: 使能
  pin 2-9   A1-A8       pin 18-11  B1-B8
  pin20  VCC            pin10  GND
```

本项目约定：**A 侧 = RP2350A（3.3V），B 侧 = 5V 总线排针。**

| 项目 | 接法 | 说明 |
|---|---|---|
| VCC（两颗） | **3.3V** | LVC 单电源，A/B 同 VCC；不要给 B 侧单独接 5V |
| /OE（两颗） | **GND** | 常使能 |
| 5V 输入 | 可直入 | 74LVC 在 VCC=3.3V 时输入端耐压 5.5V，B 侧读 5V 安全 |
| 输出高电平 | 3.3V | 6581 的 VIH 是 2.0V（TTL 电平），3.3V 够用 |

**为什么单电源 3.3V 就够**：LVC 的输入 5V 容忍，输出 3.3V 又能满足 5V TTL 的 VIH。
不需要真正的双电源电平转换。

## 2. U1：数据总线（8 位，双向）

| U1 引脚 | 接 RP2350A | 接总线 | 备注 |
|---|---|---|---|
| A1–A8 | GPIO0–GPIO7（D0–D7） | — | 必须连续，PIO 的 `out pins,N` 要求 |
| B1–B8 | — | D0–D7 | 到 374 / SID |
| **DIR (pin1)** | **GPIO11** | — | 专用方向脚，见 §4 |
| /OE (pin19) | GND | — | |
| VCC (pin20) | 3.3V | — | |

方向：

| GPIO11 (DIR) | 数据流向 | 用途 |
|---|---|---|
| **1（高）** | **A→B：RP2350A → SID** | 写寄存器。**默认状态，一直保持高** |
| 0（低） | B→A：SID → RP2350A | 只有将来读 `$D41B/$D41C` 时才拉低 |

DIR 低的时候 GPIO0–7 必须切成输入（否则两边对打）。

## 3. U2：控制信号（单向，A→B 固定）

| U2 引脚 | 接 RP2350A | 接总线 | 信号 |
|---|---|---|---|
| A1 | GPIO8 | WR# | 写选通，低有效 |
| A2 | GPIO9 | /RD | 读选通，低有效（暂时不用，留着） |
| A3 | GPIO10 | A0 | 地址相/数据相 |
| A4 | GPIO12 | **CS0#** | 本槽片选，低有效 |
| A5 | GPIO21 | **IC#** | SID 全局复位 |
| A6–A8 | 空 | 空 | 备用 |
| **DIR (pin1)** | **VCC（3.3V）** | — | **固定 A→B**，不要接 GPIO |
| /OE (pin19) | GND | — | |
| VCC (pin20) | 3.3V | — | |

U2 只做 RP2350A → 总线，方向永远不变，所以 DIR 直接接 3.3V。
**别把 U2 的 DIR 接到 GPIO9(/RD)** —— 那是 RPFM 老文档的写法，
前提是它把 /RD 和 DIR 当成同一个信号；我们分开后各管各的，更不容易出错。

## 4. 为什么 DIR 要单独一个脚

如果按 RPFM 的老做法把 DIR 直接连 /RD（`DIR = /RD`），也能工作：
写的时候 /RD=1 → DIR=1 → A→B；读的时候 /RD=0 → DIR=0 → B→A。
极性刚好对上，还省一个脚。

但这样有个隐患：**任何一次 /RD 抖动都会把数据总线翻转方向**，
一旦 GPIO0–7 还是输出状态，SID 和 MCU 就会对打。
单独用 GPIO11 控制 DIR，顺序就由我们掌握：

```
读之前：  GPIO0-7 切输入  →  DIR 拉低  →  /RD 拉低  →  采样  →  /RD 拉高  →  DIR 拉高  →  GPIO0-7 切输出
```

现在阶段根本不读，GPIO11 上电后写死 1 即可，但脚要占好，改板时不用再动。

## 5. PHI2 输入（GPIO14）

PHI2 是 1 MHz 独立晶振，由 MCU 外的电路供给 SID，同时引一根线回 MCU 让 PIO 数边沿。
**方向是总线 → MCU，不经 LVC245**（245 的 DIR 是整片翻转的，借用一两个通道会把其他通道也翻掉）。

**6581 的 PHI2 是 5V 摆幅，RP2350A 的 GPIO 不耐 5V，必须降压：**

```
晶振输出 ──[ R1 1kΩ ]──┬── GPIO14
                       │
                    [ R2 1.8kΩ ]
                       │
                      GND
```

- 5 V × 1.8/(1+1.8) = **3.21 V**，在 3.3V 之内
- 并一只 100 pF 到地，压掉边沿过冲
- 如果那颗晶振是 3.3V 供电的（型号带 3.3V 字样），可以省掉分压，直连，只串 100 Ω

## 7. 和旧文档的差异

| 项目 | 旧（`docs/引脚分配_RP2350A.md` 初版） | 现在 |
|---|---|---|
| A1 / A2 | GPIO11 / GPIO12 | **不用** |
| DIR | 没有单独脚 | **GPIO11** |
| CS0# | GPIO13 | GPIO12 |
| PHI2_IN | GPIO15 | GPIO14 |
| 总线位宽 | 13 位（D0-7 + WR# + RD# + A0 + A1 + A2） | **11 位**（D0-7 + WR# + RD# + A0） |

## 8. 固件要跟着改的三处（还没改）

1. `src/spfm_bus.pio`：`out pins, 13` → **`out pins, 11`**，`pack_bus()` 去掉 A1/A2 位（地址只留 A0）
2. `src/main.c`：`PIN_CS_BASE 13` → 16 位地址换成 **GPIO12 单脚输出**（不再需要 PIO1 的 CS 状态机，一个片选直接 `gpio_put`，上电拉低常有效）
3. `src/main.c` 新增 `PIN_DIR 11`，`spfm_bus_write_program_init()` 后 `gpio_init(PIN_DIR); gpio_put(PIN_DIR, 1);`；
   新增 `PIN_PHI2 14`，留给 PIO 数 PHI2 的状态机

这些等接线定下来再动，避免接错线时改来改去。

## 9. 上电检查顺序

1. 两颗 245 的 pin20 是不是 3.3V、pin19 是不是 0 V
2. U2 pin1 是不是 3.3V（不是悬空）
3. U1 pin1 上电后是不是 3.3V（DIR=1，写方向）
4. 万用表量总线侧 WR#/CS0#/A0 空闲时是否为高
5. GPIO14 上电后应该有 1 MHz 方波，峰值 ≤3.3 V
