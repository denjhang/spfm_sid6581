# 方案 A：74HC164 ×2

> 共用部分（U1 74LS374、U2 74HCT02、U3 74HC74、U4 74HCT32、译码方程、
> 主机侧写入序列、调试）见 [接线表_374_02_74.md](接线表_374_02_74.md)。
> **本文只写移位链这一段。**
>
> **首选方案**：HC164 是原生串行输入移位寄存器，接线最少，不需要处理锁存时序。

## 1. 追加器件

| 位号 | 型号 | 作用 |
|---|---|---|
| U5 | 74HC164（8 位串行输入/并行输出） | 计数链第 1–8 级 |
| U6 | 74HC164 | 计数链第 9–16 级 |
| — | 100nF ×2 | U5、U6 各一颗去耦 |

**只装 U5 也能跑**：tap 取第 8 级，窗口 7–8 µs，命中率约 75%，配合 `--repeat 2` 够用。
装齐两片才是确定性（13–14 µs）。

## 4. 抽头

**默认：U6 pin11（QF，第 14 级）** → 接到 U2 的 3A（pin8）和 3B（pin9）并联。
U2 的 3Y（pin10）输出 `nTAP`，接 U3 pin10（2/PRE）。

| 抽头 | 级数 | 窗口 | 用途 |
|---|---|---|---|
| U5 pin13（QH） | 8 | 7–8 µs | 只装一片时用 |
| U6 pin4（QB） | 10 | 9–10 µs | |
| U6 pin6（QD） | 12 | 11–12 µs | 临界 |
| **U6 pin11（QF）** | **14** | **13–14 µs** | **默认，确定性** |
| U6 pin12（QG） | 15 | 14–15 µs | |
| U6 pin13（QH） | 16 | 15–16 µs | 上限内，余量小 |

换抽头时**同时改两处**：U2 的 3A/3B 输入，以及 U5↔U6 的级联点（若抽头移到 U5 则断开 U6）。

## 5. 级联注意事项

1. **U5、U6 的 CP 必须是同一根 PHI2 线**，从 Y1 输出各引一根，不要串接。
2. **U5、U6 的 `/MR` 必须并在一起接 U3 pin8**。如果只清一片，另一片会残留旧数据，
   下一轮的 1 会和残留叠加，tap 提前变高、窗口变短。
3. HC164 的 A、B 内部是与关系，**两个都要接**，只接一个会悬空。
4. `/MR` 低有效，常态应为高。上电后若发现 `Wn` 恒低，先量 U5/U6 pin9 是不是被拉低了。

## 6. 调试

| 现象 | 检查 |
|---|---|
| tap 恒定不变 | CP 没接上（U5/U6 pin8）或 `/MR` 恒低（pin9） |
| tap 第 8 级有、第 14 级没有 | 级联断了：量 U5 pin13 到 U6 pin1/pin2 的通断 |
| 窗口明显比 13 µs 短 | 抽头接到了 U5 而不是 U6（默认接 U6 pin11） |
| 窗口 15–16 µs，偶尔丢写 | 抽头取太高，改回 U6 pin11 |
| 每次写窗口宽度都不一样 | 正常：13.0–14.0 µs 随触发相位变化。若波动大于 1 µs，说明 CP 上有毛刺 |
