# SID 6581 挂 SPFM 完整接线表 —— 方案 A：74HC164 ×2

> **⚠ 已废弃，不要照焊。** 本方案基于一个后来被实测推翻的前提（写入必须跨 PHI2 上升沿，
> 因此需要 13–14 µs 的窗口）。现行方案是 **三颗 IC**：
> [接线表_374_02_min.md](接线表_374_02_min.md)。
> 本文仅作为历史记录保留。
>
> 简短版：`LE = NOR(A0,/WR)` → 374 CLK；`TRIG_n = ¬A0∨/WR∨CSn` → SID pin6；
> SPFM `/WR` → SID pin7。不需要 74HC74，不需要移位链。

> **本文是一份完整的接线表，从电源到 SID 引脚全部可照焊，不依赖其他文档。**
>
> 同系列其余三份（[595.MD](接线表_374_02_74_595.md)、[174.MD](接线表_374_02_74_174.md)、[273.MD](接线表_374_02_74_273.md)）的**网络标签与本表完全一致**，
> 只有 §8「移位链」这一段的芯片与接法不同，选一份照做即可。
>
> **要解决的问题**：SID 只在 **PHI2 上升沿** 且 `/CS`、`R/W` 同时为低时采样总线，
> 而 SPFM 的 `/WR` 只有数百纳秒，单次写入约有 80% 概率丢失且无任何反馈。
> 实测与推导见 [写入时序调试记录.md](写入时序调试记录.md) §3、§4。
>
> **做法**：用 PHI2 自己当节拍器。74HC74 上半锁出写窗口 `Wn`，
> 两片 74HC164 数 PHI2 把它关掉。
> 不用 RC 单稳态——RC 宽度随温度、器件、供电漂移，还得拿示波器逐块标定。

参照源码：`E:\working\zcode-projects\arduino_sid`（midi.c + Arduino SID Shield.sch）
公共前提：`E:\working\zcode-projects\nes_apu\SPFM适配\00_SPFM总线协议.md`
FPGA 软核证据：`refs/x/reDIP-SID-master/.../gateware/sid_control.sv`、`sid_io.sv`

## 1. 这个窗口要多长

| 约束 | 数值 | 依据 |
|---|---|---|
| 下限 A：必须跨过至少一个 PHI2 上升沿 | ≥ 1 µs | 6581 datasheet：`TW` 从 φ2/CS/R-W 三者中最晚的那个算起，最小 350 ns |
| 下限 B：必须覆盖内部 18 周期轮转里可写的 6 个周期 | **≥ 12 µs** | 见 §1.1 |
| 上限：必须在下一条命令的地址相之前关断 | **< 20 µs** | 见 §1.2 |

### 1.1 为什么是 12 µs

reDIP-SID 的写条件（`gateware/sid_control.sv`）：

```systemverilog
w = ~bus_i.phi2 & ~bus_i.r_w_n && voice_cycle >= 1 && voice_cycle <= 6;
```

可写的相位是 18 周期轮转里的第 1–6 周期，**占 6 个 PHI2 周期，每 18 µs 出现一次**。

写窗口长度为 `W`，起点相对 PHI2 是随机的。要保证「无论起点在哪都能撞进那 6 µs」：

```
W + 6 ≥ 18   →   W ≥ 12 µs
```

即 **12 µs 是确定性下限**，不是建议值。窗口短于 12 µs 时命中是概率事件
（`W = 8 µs` 时约 75%，`W = 4 µs` 时约 53%）。

datasheet 只写了「φ2 上升沿 + /CS + R/W」三条电平条件，没有提 18 周期轮转。
按最严的模型（FPGA 软核）设计，两种情况下都能工作。

### 1.2 上限为什么是 20 µs

窗口开着的时候，SID 的 `/CS` 和 `R/W` 都是低，任何出现在 D 线上的字节都会被写进寄存器。
主机下一条命令的**地址字节**（内容 `addr & 0x1F`）必须落在窗口之外，否则会污染寄存器。

Path A 一条命令 4 字节 = 26.67 µs，两次命令的间隔就是 26.67 µs，
从本次数据相到位到下次地址相连 26 µs 左右。取 **20 µs** 作为设计上限，留余量。

### 1.3 取值

**目标窗口：13–14 µs（`TAP` 取第 14 级）。** 同时满足 ≥12 和 <20。
仿真验证：触发相位从 0 到 0.99 个周期变化时，实际窗口在 **13.0–14.0 µs** 之间。

### 6.1 真值表（本槽 CSn=0 时）

| A0 | /WR | LE | TRIG_n | 含义 |
|---|---|---|---|---|
| 0 | 1 | 0 | **1** | 空闲 |
| **0** | **0** | 1 | **1** | 地址相：**不触发** |
| **1** | **0** | 0 | **0 ↓** | **数据相：置位窗口锁存器** |
| 1 | 1 | 0 | **1** | 写脉冲结束，窗口靠计数自己关 |

本槽未选中（CSn=1）时 `TRIG_n` 恒为 1，任何相位都不触发。

> **设计要点**：不能用 `OR(LE, CSn)` 代替。`LE` 在空闲态也是 0（`NOR(0,1)=0`），
> 那样空闲期会误触发，在总线上产生虚假的 `/CS`+`R/W` 低脉冲。
> 必须用 `A0` 原信号判断数据相。

## 8. 移位链：U5 + U6 = 74HC164 ×2

### 8.1 工作原理

```
        TRIG_n ──┬─────────────→ U3A /PRE   （置位：开窗口）
                 └─────────────→ U3B /CLR   （清掉"数完了"标志）

 QW (U3A 1Q) ─────→ U5 A,B（移位串行输入）

 Wn (U3A 1/Q̄) ────→ SID /CS + SID R/W

 PHI2 ────────────→ U5 CP, U6 CP   （同一个时钟）

 TAP (U6 QF) ──→ U2 g3 反相 ──→ nTAP ──→ U3B /PRE

 DONE_n (U3B 2/Q̄) ─┬──→ U3A /CLR     （关窗口）
                    └──→ U5 /MR, U6 /MR（硬清链）
```

1. **U3A 是窗口本身。** `TRIG_n` 拉低 → 异步置位 → `QW=1`、`Wn=0` → SID 的 `/CS` 和 `R/W` 同时为低。
2. **U5/U6 是计数器。** `CP` 接 `PHI2`，串行输入接 `QW`。窗口一开，每个 `PHI2` 上升沿往链里推一个 1。
3. **数到第 14 格，U3B 记住"数完了"。** `TAP` 变高 → `nTAP` 变低 → 置位 U3B，
   `DONE_n` 同时关窗口、硬清链。
4. **U3B 一直保持，直到下一次 `TRIG_n`。** 这样 `TAP` 只需要出现一瞬间。

**窗口长度 = 从触发到第 14 个 `PHI2` 上升沿，即 13–14 µs。**

第 2 个触发器不是可选的：若只用 `¬TAP` 直接清 U3A，链要花一个周期才把 `TAP` 上的 1 移走，
那段时间窗口已关但 `TAP` 还是高，`/CLR` 仍被拉住，会出现时序依赖实现的毛刺。

### 8.5 接线注意事项

1. **U5、U6 的 `CP` 必须是同一根 `PHI2`**，从 Y1 输出各引一根，不要串接。
2. **U5、U6 的 `/MR` 必须并在一起接 `DONE_n`**。只清一片会让残留的 1 与新一轮叠加，
   `TAP` 提前变高、窗口变短。
3. HC164 的 A、B 内部是与关系，**两个都要接**，只接一个会悬空。
4. `/MR` 低有效，常态为高。若发现 `Wn` 恒低，先量 U5/U6 pin9 是否被拉低。

## 9. 完整译码方程与时序

```
LE      = NOR(A0, /WR)                      // U2 g1 → U1 CLK
nA0     = NOR(A0, A0) = ¬A0                 // U2 g2
t       = OR(nA0, /WR)                      // U4 g1
TRIG_n  = OR(t, CSn) = ¬A0 ∨ /WR ∨ CSn      // U4 g2
nTAP    = ¬TAP           (TAP = 链第 14 格)  // U2 g3
QW      = SR(置位=TRIG_n↓, 清零=DONE_n↓)     // U3A
Wn      = ¬QW                               // U3A 1/Q̄ → SID /CS 与 R/W
链      = shift(QW, CP=PHI2, 清=DONE_n低)    // U5/U6
DONE_n  = SR(置位=nTAP↓, 清零=TRIG_n↓)       // U3B
```

| 信号 | 原接线（[接线表_374_02.md](接线表_374_02.md)） | 本方案 |
|---|---|---|
| `LE` | `NOR(A0, /WR)` | **不变** |
| `/CS_sid` | `OR(CSn, LE)` | **`Wn`** |
| `R/W` | **`/WR`（数百 ns）** | **`Wn`（13–14 µs）** |

`Wn` 只在 `A0=1 & CSn=0 & /WR↓` 时产生，地址相永远不会出现 `Wn`，
所以原来 `OR(CSn, LE)` 那套保护不再需要——保护条件已经内建在 `TRIG_n` 里。

### 9.1 时序波形

```
PHI2    ─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌─┐_┌──
         ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾ ‾‾

TRIG_n  ‾‾‾‾‾‾\_______________________/‾‾‾‾‾‾‾   （只有几百 ns）

QW      ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\_______
                          ←── 14 个周期 ──→

Wn      ‾‾‾‾‾‾‾‾\__________________________/‾‾‾‾‾   （SID /CS + R/W）

链      ____/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\___________   第14格变高后立刻被清
TAP     ____________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\_________   只高一个沿的时间

DONE_n  ‾‾‾‾‾‾‾‾‾‾‾‾\____________________/‾‾‾‾‾‾   低到下一次 TRIG_n
```

窗口开着时 D 线上是稳定的数据字节，被反复采样 14 次写入同一个值——SID 寄存器是纯锁存器，
重复写同一值无副作用。

### 9.2 链每次都被硬清零

数完之后 `DONE_n` 拉低，同时接链的清零端和 `U3A /CLR`。所以链不是"慢慢移 0 冲掉"，
而是被硬清零，**每次写都从全 0 链开始**，第 14 格的位置每次都是同一个值。

### 9.3 上电初值

上电时各级触发器初值随机，最坏情况是 `TAP` 位恰好为 1，`nTAP` 已为低，
与 `TRIG_n` 同时作用到 U3B 的 `/PRE` 和 `/CLR`。74HC74 两端同时有效属非法状态，
这一次写只得到一个很短的窗口。

**影响只有上电后第一条写命令**，之后 U3B 被 `TRIG_n` 清掉、链被清零即恢复正常。
`sid_init()` 连写 25 条寄存器清零，第一条丢掉不影响结果，**不需要额外上电复位电路**。
想第一条也稳，就先单独发一次 `[slot,0x00,0x00,0x00]`。

`IC` 只接 SID 的 `/RES`，不要接链或 U3 的清零端——`IC` 脉宽不定，接上去会和 `TRIG_n` 打架。

`Wn` 要同时驱动 SID 的 `/CS` 和 `R/W` 两根线，74 系列的扇出足够。
若想分两根走线省一个结点，可用 **74HC125** 的两个门（`/OE` 接地常通）缓冲后分别送
pin6/pin7。**这是布线便利，不是电气必需**——不加 125 完全能工作。

> **注意 pin 8 不是 `Wn`**：pin 8 是 `PHI2`，接 Y1 的 1 MHz 晶振。
> 若把它接到 `Wn`，SID 就没有时钟，内部振荡器、包络、18 周期轮转全停，一颗音都发不出来。

### 10.1 为什么 `/CS`（pin6）和 `R/W`（pin7）接同一根线

6581 的写条件是**三个条件同时成立**：

```
/CS = 0  ∧  R/W = 0  ∧  PHI2 出现上升沿
```

前两个我们能控制，第三个控制不了——`PHI2` 是 SID 自己的自由振荡时钟。
`Wn` 是一个 13–14 µs 的低电平窗口，把它同时接到 `/CS` 和 `R/W`，就保证：

- 窗口开着的 13–14 µs 里，`/CS` 和 `R/W` **同时**为低；
- 这段时间必然跨过 12 个以上的 `PHI2` 上升沿；
- 于是第三个条件一定被满足，而且被满足十几次。

**依据一：datasheet 的 `TW` 定义**

```
TW  Write Pulse Width  min 350 ns
    "TW is measured from the latest occurring of φ2, CS, R/W"
```

"从 φ2、CS、R/W 三者中**最晚**发生的那一个开始算"——三者并列、缺一不可。
350 ns 的最小值本身也大于 SPFM 一条 BusWrite 的 `/WR` 宽度（数百 ns 量级）。

**依据二：reDIP-SID 的 RTL**（`gateware/sid_control.sv`）

```systemverilog
w = ~bus_i.phi2 & ~bus_i.r_w_n && voice_cycle >= 1 && voice_cycle <= 6;
...
end else if (cycle_cs && w && vaddr >= 0 && vaddr <= 6) begin
    v0.bytes[vaddr[2:0]] <= bus_i.data;
```

需要 `phi2` 低、`r_w_n` 低、`cycle_cs` 有效三者同时成立。

**依据三：两者在芯片里由同一个时钟沿采样**（`gateware/sid_io.sv`）

```systemverilog
phi1_io = ~phi2_io;
...
) io_r_w_n ( .LATCH_INPUT_VALUE (phi1_io), .D_IN_0 (bus_i.r_w_n) );
) io_cs     ( .LATCH_INPUT_VALUE (phi1_io), .D_IN_0 ({ cs }) );
```

`/CS` 与 `R/W` 都在 `phi1`（φ2 反相）沿被锁存。既然采样时刻相同，
两者就必须在同一时刻都为低，否则采到的组合不构成写。接成同一根线是这一要求的最强保证——
根本没有偏斜。

**为什么不把 `R/W` 直接接地**

接地也能写（`R/W` 恒低，写条件退化为 `CS=0 ∧ PHI2 沿`），但：

- **结构上不可能出现读**。`R/W` 与 `/CS` 同源，永远不会出现"CS 低而 R/W 高"的读状态，
  SID 的数据输出驱动永远不打开，绝不和 U1 的 374 或 SPFM 总线抢数据线。
- **空闲态无歧义**。窗口关闭时两者同时为高，SID 完全脱离总线。
  若 `R/W` 接地，SID 长期处于"写就绪"，将来任何对 `/CS` 的改动都可能变成意外写。
- **一根线描述一整个事务**。`Wn` 低 = "正在写这个寄存器"，示波器探一根脚就知道事务有没有发生。

**为什么不像原接线那样把 `R/W` 接 `/WR`**

那正是问题所在：`/WR` 只有数百纳秒，落在 1 µs 的 `PHI2` 周期里，
约 80% 概率不跨过任何上升沿——写不进去且无任何反馈。
这是 [写入时序调试记录.md](写入时序调试记录.md) 里 `--repeat` 现象的来源。

## 11. 总线动作表与主机侧写入序列

| A0 | /WR | CSn | LE | TRIG_n | Wn | 总线动作 | SID 侧 |
|---|---|---|---|---|---|---|---|
| 0 | 1 | x | 0 | 1 | 1 | 空闲 | 忽略 |
| **0** | **0**↓ | 0 | **↑ 1** | 1 | 1 | **地址相** | 忽略，374 抓住 `addr&0x1F` |
| 0 | ↑ | 0 | ↓ 0 | 1 | 1 | 地址相结束 | 374 保持地址 |
| **1** | **0**↓ | 0 | 0 | **0 ↓** | **0（13–14 µs）** | **数据相** | **窗口内必有一次锁存** |
| 1 | ↑ | 0 | 0 | 1 | 0（计数中） | 数据相结束 | 继续写同一值（无副作用） |
| x | x | x | x | 1 | 0（计数中） | 窗口计时 | 同上 |
| x | x | 1 | x | 1 | 1 | 本槽未选中 | 忽略 |

主机侧走固件**路径 A**（4 字节）：

```
[slot, 0x00, addr & 0x1F, data]
```

| 步骤 | 固件动作 | 总线上 | 结果 |
|---|---|---|---|
| 1 | A0=0，D=`addr&0x1F`，/WR 脉冲 | `LE` 上升沿 | 374 捕获 A0–A4 |
| 2 | A0=1，D=`data`，/WR 脉冲 | `TRIG_n` 下降沿 → `Wn` 拉低 13–14 µs | SID 在窗口内锁存 |

**`0x1F` 掩码不能省。** 改完硬件后 `--repeat 1` 就应当稳定工作；
如果还需要 repeat 才有声音，说明窗口没生效，按 §12 查。

**不要照抄原 midi.c 用 374 的 Q7 驱动 R/W。** 那样写窗口会缩回 `/WR` 的宽度，
正好把整套改造的意义抹掉。Q7 空着。

### 11.1 初始化

复位后 volume（0x18）= 0，**不写就没有声音**：

```
[slot, 0x00, 0x18, 0x0F]    // volume = 15
[slot, 0x00, 0x17, 0xF0]    // 谐振 + 滤波通道使能（按需）
[slot, 0x00, 0x16, CUTOFF]  // 截止频率（按需）
```

### 11.2 一个音符

```
[slot, 0x00, 0x00+7c, freq_lo]
[slot, 0x00, 0x01+7c, freq_hi]
[slot, 0x00, 0x05+7c, AD]
[slot, 0x00, 0x06+7c, SR]
[slot, 0x00, 0x04+7c, WAVE|1]    // 起音
```

## 12. 上电与调试

按顺序量，前一项不对就别看后一项。

| 检查项 | 做法 |
|---|---|
| ① `PHI2` | SID pin8 上应有干净 1 MHz（占空比接近 50%） |
| ② `LE` | U2 pin1：只在 A0=0 且 /WR=0 时为高 |
| ③ `TRIG_n` | U4 pin6：空闲恒高，写数据相时出现一个低脉冲。若空闲也低 → 查 U2 pin4 是否为 `¬A0`，**不要用 `OR(LE, CSn)`** |
| ④ `Wn` | U3 pin6：每次写数据相后拉低 **13–14 µs**（随触发相位在这个范围内变化，正常） |
| ⑤ `QW` | U3 pin5：与 `Wn` 反相，持续 13–14 µs |
| ⑥ `TAP` | U6 pin11 · QF · 第 14 级：每个 `PHI2` 沿往后推一格，第 14 个沿变高，随即被清零端拉低而回落 |
| ⑦ `nTAP` | U2 pin10：常态高，窗口关断那一刻出现一个短低脉冲 |
| ⑧ `DONE_n` | U3 pin8：数完后为低，下一次 `TRIG_n` 到来时变高。若一直为低 → U3 pin13 是否接 U4 pin6 |
| ⑨ `Wn` 恒低 | U3 pin1 一直被拉低。量 U3 pin8：恒高说明 `TAP` 从没到，恒低说明从没被清 |
| ⑩ `TAP` 恒定不变 | U5/U6 pin8（CP）没接上，或 pin9（/MR）恒低 |
| ⑪ `TAP` 第 8 级有、第 14 级没有 | 级联断了：量 U5 pin13 → U6 pin1/pin2 通断 |
| ⑫ 窗口明显偏短 | 抽头接到了 U5 而不是 U6（默认 U6 pin11） |
| ⑬ 连写时第二次不响应 | 链没被清：量链的清零端是否都接到 `DONE_n` |
| ⑭ 空闲时也有输出 | `TRIG_n` 接错，见 ③ |
| ⑮ 只有部分寄存器能写 | 量 U1 pin12（Q4）到 SID pin13 的通断——A4 断了就只有 0x00–0x0F 能用 |
| ⑯ 音量写了没反应 | 检查 12 V（pin28）与 5 V（pin25）是否都在；6581 缺 12 V 完全无声 |
| ⑰ 上电初态 | 374 的 Q 上电后是不定态。先写一次 `[slot,0x00,0x00,0x00]` 让它归零 |

**验收标准**：`--write-mode two-phase --repeat 1 --delay 0` 单次写入就能稳定出声，
且 `scale` 每个音高都正确。做到这两条，`--repeat` 就可以彻底撤掉。

## 13. 一句话总结

D0–D7 共享；A0 当相位；`LE = NOR(A0, /WR)` 敲 374 的上升沿；`TRIG_n = ¬A0 ∨ /WR ∨ CSn`
只在数据相写脉冲期间拉低；**74HC74 上半锁出 `Wn`（驱动 `/CS` + `R/W`），
两片 74HC164 数 14 个 `PHI2` 周期，第 14 格经下半锁存成 `DONE_n` 再关掉窗口**；
1 MHz 晶振既喂 `PHI2` 又当窗口节拍；主机一条 `[slot, 0x00, addr&0x1F, data]` 完成一次寄存器写。

**本质：把「写窗口能否撞上 PHI2 采样点」从依赖 RC 精度的模拟问题，
变成数时钟周期就能保证的确定性问题。**

## 14. 为什么选这个方案

**接线最少的方案。** 链完全在芯片内部，两片之间只有一根 `QH→A` 的线。
每片只要六根外部线：VCC、GND、`PHI2`（CP）、`/MR`、串行输入（A/B 相邻，一根线分两个脚）、
加级联或 `TAP`。没有第二时钟、没有输出使能、没有锁存级，能接错的地方本来就少。

如果你只打算做一个版本，选这个。
