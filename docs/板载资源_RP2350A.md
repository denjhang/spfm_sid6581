# RP2350A 板载资源与引脚占用（MuLuoxing / AB Pi Pico2 核心板）

> 2026-11-25。来源：用户提供的引脚分布图（`refs/rp2350/RP2350 Pico2引脚分布图.drawio.png`）
> 与主板原理图（`refs/rp2350/主板原理图.pdf`）。
>
> 这份文档只记录**板子自己已经占掉的引脚**，以及它们对我们 SID 控制器的约束。
> 我们的完整接线见 [接线表_完整_RP2350A.md](接线表_完整_RP2350A.md)。

## 1. 板载固定资源（不可挪用）

| GPIO | 板载功能 | 说明 |
|---|---|---|
| **GPIO16** | **WS2812** | 板载 4 颗 RGB 串联彩灯，800 kHz 单线协议 |
| **GPIO23** | **USER KEY** | 板载按键 |
| **GPIO24** | **VBUS** | USB 供电检测 |
| **GPIO25** | **LED** | 板载单色指示灯（心跳/状态） |
| **GPIO29** | **VSYS FB** | VSYS 分压反馈，ADC3 |

**这五个脚在 SID 控制器里一律不使用。**
GPIO16 和 GPIO25 我们已经实测用过（彩灯/心跳灯正常），GPIO23/24/29 保留原状。

## 2. 引脚分布图的三个区

图分三栏，左边是排针位置、中间是芯片本体、右边是板载外设：

- **左栏（AB Pi Pico2 列）**：GPIO0–GPIO15 一排，每隔 3 个脚插一个 GND，
  另外标出这些脚的 UART/I2C/SPI 复用功能（UART0/I2C0/SPI0 在 GPIO0–5，
  再往后是 I2C1/SPI1 等）。
- **中栏（RP2350）**：芯片丝印与 BOOT / USER 两个按键位置。
- **右栏（MuLuoxing 列）**：GPIO16–GPIO29 一排，加上 VBUS / VSYS / 3V3 / ADC_VREF
  这些电源脚，以及板载外设的标注。

## 3. 对我们 SID 接线的影响

| 我们要用的 GPIO | 是否与板载冲突 | 结论 |
|---|---|---|
| 0–7（D0–D7） | 否 | 可用 |
| 8（WR#）、9（/RD）、10（A0） | 否 | 可用 |
| 11（DIR） | 否 | 可用 |
| 12（CS0#） | 否 | 可用 |
| 13、15 | 否 | 空闲 |
| **14（PHI2）** | 否 | 可用 |
| **16（WS2812）** | **是，板载彩灯** | **不可用** |
| 21（IC#） | 否 | 可用 |
| **23（USER KEY）** | **是，板载按键** | **不可用** |
| **24（VBUS）** | **是，电源检测** | **不可用** |
| **25（LED）** | **是，板载心跳灯** | **不可用** |
| **29（VSYS FB）** | **是，电源检测** | **不可用** |

所以可用区间是 **GPIO0–GPIO22、GPIO26–GPIO28**（其中 16/23/24 已占），
我们的方案只用到 0–14、21，都在这范围内。

## 4. 结论

SID 控制器用到的 11 个 GPIO（0–14 中的 0–14、21）**没有一个落在板载资源上**，
不需要飞线，也不需要在固件里为板载外设让路——除了 GPIO16 的 WS2812 和
GPIO25 的 LED 我们主动用来做状态指示。
